# 上线与销售检查清单

## P0：公开网页试玩前

- [ ] 替换全部占位立绘、Logo 和 Boss 图，保存委托合同与商业授权。
- [ ] 使用原创或正式授权的音乐、音效、字体与配音。
- [ ] 首页加入“本作包含实时 AI 角色台词”说明。
- [ ] 加入隐私政策、数据保留周期和删除请求渠道。
- [ ] 加入年龄提示、内容举报、封禁与安全兜底。
- [ ] 对玩家输入、模型输出和日志做脱敏；API Key 永不下发前端。
- [ ] 引入持久化存档、数据库备份和服务监控。
- [ ] 限流、防刷、模型预算、超时、熔断和排队。
- [ ] 测试手机浏览器；桌面端仍作为主要体验。
- [ ] 埋点：开始、首次对话、战术选择、战斗胜负、结局、重玩、愿望单点击。
- [ ] 完成至少 100 名非团队玩家的封测。

## P0：Steam 页面与构建

- [ ] 注册 Steamworks、缴费、税务与收款资料。
- [ ] 准备商店胶囊图、截图、预告片和简中/繁中/日文/英文描述。
- [ ] 创建 Coming Soon 页面，试玩结局页引导愿望单。
- [ ] 完成 Steam Content Survey。
- [ ] 准确披露预生成和实时生成的 AI 内容。
- [ ] 对实时生成内容说明 guardrails，确保构建与披露一致。
- [ ] 不使用侵权角色、未授权声音克隆、抓取来的音乐或品牌素材。
- [ ] 加入成就、云存档、崩溃报告和手柄/键盘提示。
- [ ] 离线或 AI 服务故障时，主线仍然可完成。
- [ ] 对不同地区价格、退款和持续推理成本做财务压力测试。

## P1：正式第一章

- [ ] 2–3 小时完整章节，不以重复聊天填充时长。
- [ ] 至少三场 Boss、成长系统、装备或技能构筑。
- [ ] 每位女主有独立冲突、专属玩法和可回收的长期记忆。
- [ ] 队友之间能在明确权限下共享或隐瞒信息。
- [ ] 关键情绪节点使用作者台词或人工审核文本。
- [ ] 全量对话回归集自动跑 CI。
- [ ] 角色一致性、剧透率、保底率、首字延迟和单局成本均达到门槛。
- [ ] 日文与繁中由母语人员做角色语气校对。
- [ ] 完成内容评级、法律与平台合规审查。

## 立项停止条件

任何一项持续发生，都应先修产品而不是继续堆内容：

- 完成率低于 25%；
- 大多数测试者把它形容为“聊天机器人”，而不是 JRPG；
- 严重设定矛盾超过 0.5% 的对话轮次；
- 模型失败导致不能通关；
- 推理成本无法通过轮数、本地模式或路由控制；
- 角色美术与剧情没有形成愿望单转化；
- 用户只对越狱和色情输入感兴趣，对战斗与故事无感。
