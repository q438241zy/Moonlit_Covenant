《月蚀契约：她们会记得你》非主程序资料包（乱码修正版）

本压缩包已经针对 Windows 中文乱码问题重新处理：

1. 所有 TXT 与 Markdown 文件均使用 UTF-8 BOM 编码。

2. 所有文件名与文件夹名只使用英文、数字和下划线，避免旧版解压软件误判中文路径。

3. 同时提供 HTML 阅读版，双击即可用浏览器打开。

4. 压缩包不包含网页主程式、服务端代码、测试代码或运行配置。

目录说明：

  • documents_utf8_bom：可用 Windows 记事本、VS Code、Typora 等打开。
  • documents_html：双击 HTML 文件即可阅读。
  • visual_assets：角色预览与标题画面等图片素材。
