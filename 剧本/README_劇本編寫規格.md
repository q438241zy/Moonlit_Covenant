# 《月蝕契約》正式劇本編寫規格

> **狀態：** 鎖定提示  
> **更新日期：** 2026-10-20  
> **權威範圍：** `劇本/` 資料夾內的正式章節

## 一、章節時長

- **序章00：** 以15分鐘為目標，允許15–18分鐘。
- **第01–100章：** 每章以10分鐘為主，標準範圍8–12分鐘。
- **第101章及以後：** 每章以15分鐘為主，標準範圍13–18分鐘。
- 時長計算包含玩家可見劇情、必要移動與核心戰鬥教學；不包含編劇註記、AI內部判定文字，以及玩家停留在輸入框思考的時間。

## 二、檔案格式

- 每章一個獨立 Markdown 檔案。
- 檔名格式：`章號章名.md`，例如 `00起源.md`、`01導師.md`、`02紅髮女孩.md`。
- 每個分鏡以二級標題命名，例如：`## 分鏡02-07｜自由輸入：怎麼攔`。
- 每個分鏡之間使用獨立的 `---` 分隔。
- 章末必須附上正史變數、存檔點與下一章接口。

## 三、AI遊戲對話規則

- 不顯示傳統固定選項，玩家以對話框自由輸入台詞、動作或戰術。
- AI分開判定表達品質、真實意圖、道德方向、可執行性、既有承諾與角色邊界。
- 說得漂亮不等於正面；操縱、欺負、欺騙或要求女主獻祭，仍依真實意圖產生罪惡感與後果。
- 玩家提出超出當前能力的行動時，世界不配合憑空生成奇蹟，必須按角色能力、環境和風險演出。
- 不可逆事件使用角色在世界內復述與追問，不使用「確定／取消」按鈕。

## 四、每章最低戲劇要求

每章至少完成以下四步：

1. 建立角色當前目標；
2. 發生一個會迫使角色行動的衝突；
3. 至少一名角色作出不可忽略的選擇；
4. 留下明確結果、變數或下一章鉤子。

禁止用重複對白灌滿時間，也不為湊章數把同一個完整衝突任意切斷。

## 五、目前正式順序

1. `00起源.md`：黑龍焚毀赫麥村，亞克立下屠龍誓言。
2. `01導師.md`：白·可恩擊退黑龍，艾琳死亡獲確認，托比由可恩收養。
3. `02紅髮女孩.md`：亞克註冊冒險者，首次遇見莉亞並參與街巷追捕。
4. `03臨時契約.md`：莉亞簽下高階陪同，與亞克組成臨時隊伍追查黑晶；舊磨坊突入依規定暫緩。
5. `04舊磨坊.md`：莉亞以無聲繩訊派亞克從乾水渠潛入舊磨坊，看清晶架與帳本，認出被擄的瑪拉與女兒波莉；鑰匙在唸禱文的人身上，兩人沒有救人就撤出，救援定在大車換鏈裝箱的那一夜。
6. `05大車之夜.md`：換鏈裝箱的那一夜，鏈子全上了箱，莉亞卻回一下「停」；亞克等到她撞門壓箱、盾落，再敲斷哥布林咒徒長的大頸圈，在黑暗中以「報數」救出瑪拉與波莉；唸禱文的人只供出「霧潮沼林」，莉亞先簽隊長欄，臨時契約轉為正式隊伍。
7. `06草莓蛋糕停戰.md`（審閱稿，待作者核可；核可前不優先於設定集）：護送商隊前往霧港，沒有頸圈的沼地食人魔在鹽沼橋上抽走輪下的墊板，莉亞自己把盾塞進輪下撐車，准亞克扶一次腰帶；兩人沒有任何約定信號就把車推過斷橋，橋過了她收回許可；林邊旅店裡她點草莓蛋糕被撞見，換來停戰，藍色爆炸把一枚齒輪砸進蛋糕盤。
8. `07爆炸來自林邊.md`（第一輪審閱稿，待作者核可；核可前不優先於設定集）：莉亞循藍光與齒輪查到一箭之內的林邊，米婭·玲登場，把失控說成「非計畫拆解」；拾鐵機專找最大塊的鐵，莉亞的盾響規矩撞上米婭的雷理，她三條規矩不改，只把今晚的退路改到導雷樁後，說「……那就抓完整的」；三人第一次臨時編成拉下急停環，事故帳記「責任：未定」；齒輪上的奶油被問到，核心是一顆沒有編號、從裡面往外蝕的潮晶，晶底的黑環與七環拓圖相合。
9. `08金律只有一毫米.md`（第一輪審閱稿，待作者核可；核可前不優先於設定集）：莉亞收下潮晶，說「這次，不離手」，讓「證人」米婭睡院子、天一灰帶路去量潮的老站；米婭在證據出來以前先修好屋簷、賠了補給，拆銹死的銷子之前先問，把那枚裂齒輪裝回潮門絞盤；米婭要「不帶火的金」，亞克自己交出、或由莉亞替他說「他有。……很弱。」，他的金律只在莉亞喊「硬」的一瞬讓裂齒咬住，棘爪扣上一毫米，潮門在大潮前關上，釘在牆上的試燈迴路保住；十七號的記錄證明核心在刻號之後、裝機之前被換，細環是從裡面長出來的，米婭承認晶是自己裝的、沒翻過底，仍在「責任」一欄自述，莉亞署名並報上「莉亞」，交出頸圈與那箱黑晶的事實；米婭沒有樣本，只比對出「像同一種蝕」並說出平安石的原理，莉亞把潮晶交給她；米婭以客座身分跟著證物進霧港，帳上記下三個名字，潮平之後聽潮針的筆尖還在抖，測到霧港底下「很多個，疊成一個」的心跳，第一幕收束。
10. `09霧港失蹤者.md`（第一輪審閱稿，待作者核可；核可前不優先於設定集）：近午退潮進霧港，橋柱上貼著三張寫了名字的尋人單；在分會交單、領06的報酬，分會長伊涅絲問亞克「水裡有人喊救命——你做什麼？」，莉亞不替他答，伊涅絲說出「先喊，再伸，再拋。最後才是跳」與「缺的是會回家的」；莉亞把客座記在自己名下，接下證人名字剪去的失蹤案，說「問人，你去」；米婭讀出潮晶一潮一層、那顆晶的黑從最裡面那一層就有了，撿晶人只說下游的口子偶爾撿到中間灰的晶，莉亞把換晶線索延到「人，先。晶，晚點」；莉亞把五張證詞交給亞克排，線索收斂成「舊浴場後溝——東口。潮回來的時候」，米婭的潮時指向今天黃昏；莉亞說「這次——盾，嚇人」，派亞克一個人去問燒水的老婦，問出池底的溝通東口與「鏡中，紫髮」的證詞；黃昏潮回來，黑色的根在眾人眼前把碼頭工人拖進東口柵欄，莉亞用盾封住缺口，把「後面的人」交給亞克，落水的魚販被拉上來；伊涅絲說出名字「達利」與「柵欄以下，歸分會」，閘要等底下的水退了、明早才開，莉亞答「天亮」，寫下「霧港底下——有人」，「救回」那一欄空著；外面在退，柵欄底下還在漲。
