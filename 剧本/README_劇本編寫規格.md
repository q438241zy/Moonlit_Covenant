# 《月蝕契約》正式劇本編寫規格

> **狀態：** 鎖定提示  
> **更新日期：** 2026-07-23  
> **權威範圍：** `劇本/` 資料夾內的正式章節

## 一、章節時長

- **序章00：** 以15分鐘為目標，允許15–18分鐘。
- **第01–100章：** 每章以10分鐘為主，標準範圍8–12分鐘。
- **第101章及以後：** 每章以15分鐘為主，標準範圍13–18分鐘。
- 時長計算包含玩家可見劇情、必要移動與核心戰鬥教學；不包含編劇註記、AI內部判定文字，以及玩家停留在輸入框思考的時間。

## 二、檔案格式

- 每章一個獨立 Markdown 檔案。
- 檔名格式：`章號章名.md`，例如 `00起源.md`、`01導師.md`、`02紅髮女孩.md`。
- 每個分鏡以二級標題命名，例如：`## 分鏡02-07｜自由輸入：怎麼攔`。
- 每個分鏡之間使用獨立的 `---` 分隔。
- 章末必須附上正史變數、存檔點與下一章接口。

## 三、AI遊戲對話規則

- 不顯示傳統固定選項，玩家以對話框自由輸入台詞、動作或戰術。
- AI分開判定表達品質、真實意圖、道德方向、可執行性、既有承諾與角色邊界。
- 說得漂亮不等於正面；操縱、欺負、欺騙或要求女主獻祭，仍依真實意圖產生罪惡感與後果。
- 玩家提出超出當前能力的行動時，世界不配合憑空生成奇蹟，必須按角色能力、環境和風險演出。
- 不可逆事件使用角色在世界內復述與追問，不使用「確定／取消」按鈕。

## 四、每章最低戲劇要求

每章至少完成以下四步：

1. 建立角色當前目標；
2. 發生一個會迫使角色行動的衝突；
3. 至少一名角色作出不可忽略的選擇；
4. 留下明確結果、變數或下一章鉤子。

禁止用重複對白灌滿時間，也不為湊章數把同一個完整衝突任意切斷。

## 五、目前正式順序

1. `00起源.md`：黑龍焚毀赫麥村，亞克立下屠龍誓言。
2. `01導師.md`：白·可恩擊退黑龍，艾琳死亡獲確認，托比由可恩收養。
3. `02紅髮女孩.md`：亞克註冊冒險者，首次遇見莉亞並參與街巷追捕。

此資料夾內較新的正式章節，優先於整合設定集中尚未同步的舊版章節摘要。
