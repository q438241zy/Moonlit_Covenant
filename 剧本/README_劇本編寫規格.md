## 二、檔案格式

- 每章一個獨立 Markdown 檔案。
- 檔名格式：`章號章名.md`，例如 `00起源.md`、`01導師.md`、`02紅髮女孩.md`。
- 每個分鏡以二級標題命名，例如：`## 分鏡02-07｜自由輸入：怎麼攔`。
- 每個分鏡之間使用獨立的 `---` 分隔。
- 章末必須附上正史變數、存檔點與下一章接口。
- 正式29、30的路線版本共用章號與檔案，分版寫在同一章內（提案3.12）；分版分鏡標題的寫法在寫正式29時定。
- 番外每篇一個檔案，放在 `剧本/番外/`，檔名以番外編號開頭（例如 `ex001…md`）；表頭寫明「時間窗：正式X–Y之間」。番外章末沒有下一章接口（`end.next` 為空），只列 `EX_*` 變數與那一條可回憶的記憶（提案4.7）。

## 三、AI遊戲對話規則

- 不顯示傳統固定選項，玩家以對話框自由輸入台詞、動作或戰術。
- AI分開判定表達品質、真實意圖、道德方向、可執行性、既有承諾與角色邊界。
- 說得漂亮不等於正面；操縱、欺負、欺騙或要求女主獻祭，仍依真實意圖產生罪惡感與後果。
- 玩家提出超出當前能力的行動時，世界不配合憑空生成奇蹟，必須按角色能力、環境和風險演出。
- 不可逆事件使用角色在世界內復述與追問，不使用「確定／取消」按鈕。收押、處決令與伴侶點名另照提案3.11.4、3.14.7的確認協定：確認節點用 `CF_` 前綴；嚴格意圖只在模型判定與詞法檢查一致、或玩家一字不差說出世界內給的固定句式時成立；沉默等於撤回；這些節點的反應全部寫死（`reactionFixed`）。正式30沒有任何殺令入口（提案3.8）。
- 主線（含主線劇情戰）維持自由輸入、由AI判定，結果由劇本寫定；上場含亞克在內最多3人（核#13第3條；提案§六A層）。唯一使用指令選單的是另開的技能戰（委託板），屬作者對本節第一條的明文例外（核#14；提案§八#35），結果不寫回正史，不讀不寫信賴、旗標與結局傾向。
- 主線判定只讀每位在場角色最多3句已解鎖劇情技能的世界內描述；技能顏色、等級、轉蛋物、服裝、武器一概不讀。轉蛋服裝在主線、正式26–30與所有結局永不顯示（提案§五、§六；技能稿；服裝稿1.1）。
- 亞克永遠弱：他贏不了任何一場一對一，會的是報數、記帳、等時機、分派，以及在一毫米處出手；帝國是被他帶回家的人打下來的（提案§一第3條、3.4）。
- 君主傾向（`MONARCH_*`）的分數只來自作者寫在意圖上的 `set.add`，模型永遠不寫；不做數值條，改用世界內的暗示讓玩家辨識路線（提案3.9、3.14.6）。
- 提示行、自由輸入提示、系統提示與章末記錄一律寫「亞克」（遊戲中為 `{PLAYER_NAME}`），不寫「你」；角色對白裡的「你」照常（核#12 B14；提案4.2）。

## 四、每章最低戲劇要求

每章至少完成以下四步：

1. 建立角色當前目標；
2. 發生一個會迫使角色行動的衝突；
3. 至少一名角色作出不可忽略的選擇；
4. 留下明確結果、變數或下一章鉤子。

禁止用重複對白灌滿時間，也不為湊章數把同一個完整衝突任意切斷。

**戰爭章模板**（正式22起的戰爭章，約10分鐘，每章最多一場戰鬥；提案4.2）：

1. 帳頁（20–30秒）：上一章以後的戰事、名字、「本月，往拱潮門」。
2. 軍議（約2分鐘）：一個自由輸入，最多四個聲音；節點 `kind: "council"`。
3. 進軍與交涉（約1分半）：先喊、再伸。
4. 唯一一戰（3–4分鐘，2–3回合）：場上是亞克加兩人；全軍戰況用旁白報數交代，其他戰線用「戰線」行。21、29、30的「三隊×三人」只輸入亞克那一隊。
5. 餘波與填帳（約1分半）：報數，宣讀死者；救回、沒回來、對面、本隊過失、監督意見。
6. 治理拍與營火（約1分半）：傾向主要在這一拍累積；輕鬆與擦邊放在這裡，不和血同一節拍（§六）。
7. 托比的信（30秒）。

軍議的代價一律在決策之前說出口；屠城、處決、焚城這類不可逆命令由將領在世界內復述並追問一次；不設標準答案。正式29的夜晚順序與正式30的加冕順序另照提案3.11.5、3.8。

7. `06草莓蛋糕停戰.md`：護送商隊前往霧港，沒有頸圈的沼地食人魔在鹽沼橋上抽走輪下的墊板，莉亞自己把盾塞進輪下撐車，准亞克扶一次腰帶；兩人沒有任何約定信號就把車推過斷橋，橋過了她收回許可；林邊旅店裡她點草莓蛋糕被撞見，換來停戰，藍色爆炸把一枚齒輪砸進蛋糕盤。
8. `07爆炸來自林邊.md`：莉亞循藍光與齒輪查到一箭之內的林邊，米婭·玲登場，把失控說成「非計畫拆解」；拾鐵機專找最大塊的鐵，莉亞的盾響規矩撞上米婭的雷理，她三條規矩不改，只把今晚的退路改到導雷樁後，說「……那就抓完整的」；三人第一次臨時編成拉下急停環，事故帳記「責任：未定」；齒輪上的奶油被問到，核心是一顆沒有編號、從裡面往外蝕的潮晶，晶底的黑環與七環拓圖相合。
9. `08金律只有一毫米.md`：莉亞收下潮晶，說「這次，不離手」，讓「證人」米婭睡院子、天一灰帶路去量潮的老站；米婭在證據出來以前先修好屋簷、賠了補給，拆銹死的銷子之前先問，把那枚裂齒輪裝回潮門絞盤；米婭要「不帶火的金」，亞克自己交出、或由莉亞替他說「他有。……很弱。」，他的金律只在莉亞喊「硬」的一瞬讓裂齒咬住，棘爪扣上一毫米，潮門在大潮前關上，釘在牆上的試燈迴路保住；十七號的記錄證明核心在刻號之後、裝機之前被換，細環是從裡面長出來的，米婭承認晶是自己裝的、沒翻過底，仍在「責任」一欄自述，莉亞署名並報上「莉亞」，交出頸圈與那箱黑晶的事實；米婭沒有樣本，只比對出「像同一種蝕」並說出平安石的原理，莉亞把潮晶交給她；米婭以客座身分跟著證物進霧港，帳上記下三個名字，潮平之後聽潮針的筆尖還在抖，測到霧港底下「很多個，疊成一個」的心跳，第一幕收束。
10. `09霧港失蹤者.md`：近午退潮進霧港，橋柱上貼著三張寫了名字的尋人單；在分會交單、領06的報酬，分會長伊涅絲問亞克「水裡有人喊救命——你做什麼？」，莉亞不替他答，伊涅絲說出「先喊，再伸，再拋。最後才是跳」與「缺的是會回家的」；莉亞把客座記在自己名下，接下證人名字剪去的失蹤案，說「問人，你去」；米婭讀出潮晶一潮一層、那顆晶的黑從最裡面那一層就有了，撿晶人只說下游的口子偶爾撿到中間灰的晶，莉亞把換晶線索延到「人，先。晶，晚點」；莉亞把五張證詞交給亞克排，線索收斂成「舊浴場後溝——東口。潮回來的時候」，米婭的潮時指向今天黃昏；莉亞說「這次——盾，嚇人」，派亞克一個人去問燒水的老婦，問出池底的溝通東口與「鏡中，紫髮」的證詞；黃昏潮回來，黑色的根在眾人眼前把碼頭工人拖進東口柵欄，莉亞用盾封住缺口，把「後面的人」交給亞克，落水的魚販被拉上來；伊涅絲說出名字「達利」與「柵欄以下，歸分會」，閘要等底下的水退了、明早才開，莉亞答「天亮」，寫下「霧港底下——有人」，「救回」那一欄空著；外面在退，柵欄底下還在漲。
