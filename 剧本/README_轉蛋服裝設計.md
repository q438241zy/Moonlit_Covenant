## 二、五類服裝的框架

### 2.1 泳装（`swimsuit`，★5）

- **框架**：真泳裝，對應兩篇海邊番外（ex002 霧港外海沙洲、ex009 翠影南岸的海灘與龍舟祭）。世界內的來由：鑄金工坊用「防水魔纱」裁的新式泳衣，在港口城市流行起來。八人的剪裁不同：
  - 四套比基尼：塞雷娜、莉莉絲、奧菲利亞、艾拉；
  - 四套連身或分身：莉亞、米婭、芙蕾婭、伊芙琳。

  分配依性格：自信的穿比基尼；嚴肅、害羞、大姐姐型穿得遮一些。
- **濕身感**：髮梢濕成束，頭髮和肩上有3–8顆水珠，泳衣布料有一道光澤高光帶。不畫皮膚上的水痕流線，胸口不畫水珠。
- **背景 `bgMotif`**：月夜海岸。夜光浪花、沙丘弧線、遠處燈塔，月光從左上照入，符合 ART-DIRECTION §1，也避免變成大白天的寫真。
- **12+ 柔和版**：同一件泳裝加上每個人各自的罩衫層（第三節）。輸出到 `costumes/soft/`。
- **道具世界內化**：水槍是米婭自製的改裝品（不帶名字）；衝浪板寫成「雾港浪板」；防曬油寫成「翠影药草防晒膏」。
- **徽記放在**泳衣正面的金屬扣環或吊墜；**紋樣**放在側縫滾邊或道具上。

### 2.2 婚礼礼服（`wedding`，★5）

- **框架**：「禮服商會新季的婚禮主題樣衣——試穿日」，對應 ex003 白塔朝聖者拱廊街。禮服店是鑄金商會開的分店，不是教堂。
- **不暗示婚約或誓約的做法**（婚姻和誓約在正典裡屬於結局，而且只出現在仁慈結局的三年後尾聲）：
  1. **文字**：類型名用「婚礼礼服」，不用「新娘」。全部服裝文案禁用這些詞：誓约、婚约、求婚、新郎、嫁、娶、夫人、王后、皇后、妃、后宫、侍寝、戒指。其中「妃」「后宫」「侍寝」屬於好色君主路線，特別要避開。
  2. **畫面**：不畫戒指，不畫新郎或男性剪影，不畫祭壇或教堂，沒有誓詞，沒有兩人名字的緞帶，不用誓約金光或誓約晶體發光當主視覺。頭紗不遮臉，只別在後方。背景是禮服店：玻璃拱頂、落地鏡框、布料捲。
  3. **系統**：擁有或裝備婚禮服，不改變任何關係數值。ex003裡亞克是搬布料、捧裙襬的幫手，**永遠不站新郎位**，也沒有告白、求婚或「差一點的吻」段落。宣傳圖不做「八人穿婚紗圍著亞克」的合照。
  4. **和結局、真婚禮分開**：任何結局裡的典禮另畫正典服，永遠不沿用轉蛋婚禮服；好色結局空殿裡的「八件婚紗」是劇情道具，也不用這套設計。不做穿轉蛋婚紗的真婚禮番外。
  5. **尊重角色的婚約條件**（設03:735–746）：伊芙琳那套刻意世俗化（「不以宗教名義神聖化」）；奧菲利亞那套只用她自己氏族的顏色（「不把婚姻當吞併」）。
- **徽記放在**腰帶結或領口的胸針；**紋樣**織進蕾絲重複的花樣。

### 2.3 女仆装（`maid`，★3，改版）

- **框架**：霧港橋頭旅店（ex001）或拱廊街咖啡館的女侍制服，做成風格化的版本。
- 現行版是八人共用一套黑色長袖古典款。改版拆成**三種剪裁**：
  - 古典長款：塞雷娜、芙蕾婭、奧菲利亞；
  - 咖啡館短泡泡袖款：米婭、伊芙琳、艾拉；
  - 工作款（捲袖、厚圍裙）：莉亞、莉莉絲。

  再加上每人一件道具。
- 領口都在胸骨以上，兩檔共用一張圖。15+ 只在番外文本裡多一些俏皮的服務台詞（`text15`）。不做短裙或吊帶襪這類取向；胸像也畫不到。
- **用語**：這是旅店與咖啡館的工作制服，不是侍從身分。文案禁用「主人」「侍奉」「侍从」，理由和技能稿避開「护主」相同——征服帝國與好色君主路線之下，這些詞會讓女主讀起來像屬下。
- 徽記和紋樣的位置不變：圍兜刺繡、腰帶上一排紋樣。

### 2.4 运动短袖（`sportwear`，★3）

- **框架**：世界內的「騎士團／公會操練衫」，棉質圓領**短袖**，八人一律短袖，不做無袖、不透、不短版。對應 ex004 聖都騎士團演武場的操練日。
- 號碼布因為規範禁用 `<text>`，**用她的徽記代替數字**；**紋樣**沿袖口滾邊排一列。
- 汗水只畫在額角，不畫汗濕透視。
- 道具世界內化：碼錶寫成沙漏或零號計時；應援彩球寫成綴小鈴的彩帶。
- 模板限制：髮型由女主模組決定，換裝時不變，只能加頭帶或髮飾。

### 2.5 OL装（`office`，★4，異界IF）

- **框架**：「异界IF·现代通勤」，前提是「如果她們生活在另一個世界的現代都市」。艾瑟蘭是早期工業化的奇幻世界（設02:218–220），所以這套**只做IF**：
  - 卡面加「IF」角標；
  - 只出現在 ex010 平行現代商場、換衣間和技能戰；
  - 永遠不進正典番外，正典番外的商會職員、文書裝都用番外默認服。
- 西裝外套加襯衫，下半身在畫外。15+ 的擦邊**只靠神態**，例如秘書式的挑釁或眼鏡，不靠暴露。
