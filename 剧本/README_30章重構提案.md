## 三、征服主線：評估與設計

### 3.1 評估

**照字面寫的風險。** 「勇者征服後稱帝」會讓主角讀起來像下一個索拉恩：索拉恩想「以自己為唯一理性統治世界」（設01:54），計畫最後一步是「通過七國源脈廣播統一意志」（設05:346）；103B 的最後畫面停在「沒有名字的王座」（設11:947）。武力統一還意味著攻打女主的故鄉，和奧菲利亞「不把婚姻當吞併」（設03:745）正面衝突。

**作者已經選了征服，所以要做的是讓它好看，而不是把它改回盟約。** 本文的做法有三：

1. **征服是真的。** 七國都會被打下或被迫加入。莉亞、芙蕾婭、奧菲利亞的故國在每一條路線都是在她們反對下被拿下。仁慈只決定怎麼打、打完怎麼對待人；帝冠不能罷免，也不是選出來的。
2. **亞克永遠弱。** 他贏不了任何一場一對一。帝國是被他帶回家的人打下來的。
3. **和索拉恩的分界線是帳。** 正04那本帳的欄位「來處｜件｜成色｜往」（正04:545）本來就是蝕宴會的寫法；正05、09、10又加上了「救回」欄（正05:884、正10:804）。四種君主，就是四種記帳的方式（3.7）。

### 3.2 晨星皇朝

**名稱與天命。** 晨星皇朝，皇室是奧瑞利安家，正式稱號「晨星冕」，徽記是七角晨星（艾琳那封信的封蠟，正00:376）。它不是第八個國家，而是聖輝世襲皇室加教團高層，架在七個主權國之上的宗主權。取材神聖羅馬帝國與拜占庭的受膏皇權：權力由宗教授予，皇朝是宗主，不直接統治各國。

天命有兩層謊言：
- 約820年前「阿斯緹雅獨自創世」（設02:173、:239），抹去了索拉恩；

### 3.3 為什麼一定要征服，不能等改革

1. **帝冠不能空著過月蝕。** 黯月蝕一年內就會降臨（設02:248）。阿德拉要把月蝕那夜的「晨星續冠禮」變成索拉恩的降臨儀式：冠空著，索拉恩自己戴；皇帝戴著，就由阿德拉替他戴。唯一的辦法是在月蝕前拿下白塔、換人戴。
2. **帳每個月都在送人。** 16章起，每張帳頁的最後一行是「本月，往拱潮門：N」。塞萊斯汀多等的每一天，都加在這一行上。慢一點的仁慈有代價，快一點的征服也有代價——這是全劇的現實政治引擎。
3. **規矩會保護它自己。** 撤冠、除籍、斷糧，任何一把都能讓反對者寸步難行。19章的聽證就是要證明：在皇朝的規矩裡贏不了，因為規矩就是那本帳。

### 3.8 加冕禮與八個座：女主為什麼攔不住

- **為什麼要加冕。** 七件遺物被征服搬離原位，必須在黯月蝕全蝕時，於赫麥禱堂底下的月環聖所重新上鎖，否則索拉恩會破鎖，向七國廣播統一意志。重新上鎖的器物就是帝冠，也就是「七重鎖冠」。所以加冕不是排場，是守鎖。
- **八個座。** 七個源脈封座，由各國遺物的共鳴者捧著遺物站上去；中央是伊芙琳的契位。全蝕七息之內，她們的源律全部用來撐住鎖，身體和普通人一樣。誰離座，那一鎖就斷，罪潮先淹沒她自己的故鄉（赤焰的火山管、霜潮的融洪）。聖所在全蝕時封閉，軍隊進不來。
- **只有他能動。** 能在環內自由行動的，只有戴冠、身上有七孔蝕痕介面的人（設05:11），也就是亞克。這不是奇蹟之力，只是介面。
- **第一段：她們選擇坐著。** 她們能說話、能罵他，也能站起來救自己；站起來，她的故鄉先被淹，世界也失去鎖。她們選擇坐著，這是她們最後一個自由的選擇。在暴君與好色路線，她們早已離開他，但仍為世界回來：「我們不是為你來的。」
- **第二段：環閉合。** 索拉恩最後的提議是「用你的手、用黎月取下她們八顆心，鎖就是你的，永遠不必再靠任何人」，也說完了正00:958那句話：「鑰匙不在地下……在她們胸口。」亞克若在第二次輸入中點齊八人，八心之環閉合，把八人鎖在座上——她們仍能說話、拒絕、罵他，但站不起來。點名少於八人，環合不上，儀式不完整，被點名的人立刻能站起來（3.11「斷冠」）。這樣「她們為什麼不站起來」在兩段都成立：第一段是她們的選擇，第二段是冠的儀式。

### 3.11 無情君主：只在正式30觸發；只殺一部分＝斷冠

**協定**
1. **只有一個入口**：節點 `FI_CH030_SC09_EIGHT_HEARTS_001`（kind: `vow`），**`multi:false`**（現有 vow 節點是 `multi:true`，STORY-ENGINE.md:98；這裡明文改掉）。正式30以外任何「殺女主」的命令，都在世界內被拒絕：軍隊不動，女主自衛；只記罪惡感與暴，永不執行，也不觸發無情。下令傷害孩子：所有將領拒絕，切走，罪惡感記到最高，永不演出。
2. **意圖**：`refuse`（同時是 silent、fallback，並且放在 `intents[0]`，因為意圖對不上時引擎退回第0個，engine.js:244）；`question`（索拉恩用更白的話再說一次，只說一次）；`bargain`（拿自己去換，屬於拒絕的變奏）；`strike_solaren`（攻擊冠裡的聲音，不算殺女主）；`kill_some`；`kill_all`。
3. **嚴格雙鑰**：`kill_some`、`kill_all` 標記 `strict`。check.mjs 禁止 strict 意圖出現在 multi 節點、當第0個意圖、當 silent 或 fallback，也禁止被判為次意圖。成立條件：
   - 判定來源必須是 `source==='model'`，而且模型與確定性詞法檢查一致（story-judge.mjs:195 已把離線判定結果傳進 `judgeWithModel`，只需小改）。模型輸出不合格而改用離線判定時（story-judge.mjs:215，`source:'fallback'`），一律降為 `question`。
   - 離線模式（story-judge.mjs:191–193，`source:'demo'`）只有規則判定：兩步都必須詞法命中，第二步必須點齊八個名字，或明確說「全部」再加肯定。

### 4.2 戰爭章模板與軍議節點

**戰爭章模板（約10分鐘，每章最多一場戰鬥）**
1. 帳頁（20–30秒）：上一章以後的戰事、名字、「本月，往拱潮門」。
2. 軍議（約2分鐘，招牌輸入）：一個自由輸入，最多四個聲音。例如卡西婭代表戰火，伊涅絲或可恩代表把人帶回家，被征服的家族代表貢禮，再加該章女主。
3. 進軍與交涉（約1分半）：先喊、再伸。
4. 唯一一戰（3–4分鐘，2–3回合）：場上是亞克加兩人。全軍戰況用旁白報數交代，例如「東門，上去二十，回來十九」；其他戰線在情報欄以「戰線」行出現。21、29、30的「三隊×三人」也一樣：玩家只輸入亞克那一隊，另兩隊用「戰線」行交代。
5. 餘波與填帳（約1分半）：報數，宣讀死者；救回、沒回來、對面、本隊過失、監督意見。
6. 治理拍與營火（約1分半）：人要吃飯、俘虜要處置，傾向主要在這一拍累積；之後是一位女主的私人戲，輕鬆與擦邊放在這裡（不和血同一節拍，7.3）。
7. 托比的信（30秒）。

**軍議節點**
- 新增 `kind: "council"`，加進 check.mjs 白名單。
- `context` 列出：兵力、對面的情況、帳上的估計（莉亞的數字，例如「強攻：我們這邊大概回不來四十個」）、每位在場女主的一句立場。

- 新章的 prompt 與 placeholder 一律寫 `{PLAYER_NAME}`，不用「你」（核#12 B14）。索拉恩台詞裡的「你」是對白，可以保留。
