# 01｜核心企划与叙事支柱

## 1. 项目定位

《月蚀契约》是一款以 **七国冒险、队伍关系、AI自由对话和多结局** 为核心的幻想 JRPG。玩家扮演十八岁的乡村少年魔剑士 `{PLAYER_NAME}`，默认名“亚克”。他在圣教洗礼后拥有金、木、水、火、土、光、暗七种源律适性，却每一种都弱得近乎无用。

七国正被七宗罪的“罪律”污染。它们不是抽象说教，而是由国家制度、民众欲望和远古魔兽共同形成的灾难：贪婪让资源被垄断，嫉妒让生命互相复制吞噬，怠惰让人宁愿停在过去，愤怒让战争不断自我证明，暴食让传承变成无止境占有，傲慢让信仰自称唯一真理，色欲则把亲密扭曲成占有与控制。

玩家会与八位女主角建立关系。七位分别与一种源律和罪律产生强烈共鸣；伊芙琳则是“纯结”持有者，不代表道德上的完美，而代表 **关系仍能保持自愿、清醒和可拒绝**。她是七种力量能够共存的连接点。

## 2. 标题含义

- **月蚀**：天象、魔力灾变，也是人心被放大时的隐喻。
- **契约**：反派理解为支配；旧圣教理解为牺牲；七国政权理解为交换；主角团队最终将它重写为知情、自愿、可撤回、共同承担后果的关系。
- **月蚀契约**：终章仪式。它既能使堕神索拉恩吞噬七律，也能由亚克、八位女主与七国民众共同改写成新的世界规则。

## 3. 四条叙事支柱

### 3.1 七宗罪是压力下的错误答案

七位对应女主并非“罪的化身”，而是最容易被某种错误答案诱惑。

| 女主 | 罪律诱惑 | 她真正需要学会的事 |
|---|---|---|
| 米娅／贪婪 | 掌握越多技术就越安全 | 知识需要共享，也必须承担后果 |
| 莉莉丝／嫉妒 | 别人拥有的家、身份和爱都夺走了她的人生 | 她可以重建自己的位置，而非复制或毁掉别人的 |
| 芙蕾娅／怠惰 | 只要时间冻结，就不必面对失去 | 悲伤需要流动，温柔也包含结束 |
| 莉亚／愤怒 | 永不后退、立刻反击才能保护人 | 撤退、倾听和求援也是守护 |
| 奥菲利亚／暴食 | 吞下所有祖先记忆才能成为完整龙族 | 传承可以选择，不必把一切都塞进自己 |
| 艾拉／傲慢 | 只要站在“正确的光”里，命令就是正义 | 判断必须由自己承担，光明也可能犯错 |
| 塞雷娜／色欲 | 只要占有、监视和被需要，就不会被遗弃 | 亲密不是控制，门开着仍愿意回来才是选择 |
| 伊芙琳／纯结 | 她不是无罪，而是不被单一罪律定义 | 她必须停止把自己献给所有人，才能真正连接他人 |

### 3.2 冒险是关系的压力测试

每个国家都给玩家一个“看似高效、实际危险”的解决方案。例如夺走技术、强制解冻、公开处刑、替角色作决定或把某人当作祭品。队伍关系会在这些选择中暴露真实状态。高好感并不能自动解决问题；玩家必须让角色拥有知情权和行动权。

### 3.3 力量来自低起点的共同成长

亚克并非开局全能。他只能让剑尖闪过极弱的七色火花。每个国家会教他一种源律的“正确结构”，每位对应女主则让他理解那种力量最危险的滥用方式。属性成长因此同时是数值成长、地图解锁和人物成长。

### 3.4 黑暗路线必须看得见地形成

病爱、七罪吞噬和堕神接受结局不会由一次错误选项突然触发。玩家会在第50–100章反复遇到小分支：是否纵容监视、是否利用某人的依赖、是否隐瞒多线暧昧、是否用罪核换取捷径、是否让一个人替全队承担代价。每一次选择都留下视觉、对白和系统反馈，让坏结局既震撼又公平。

## 4. 世界核心结构

### 4.1 七种源律

世界基础魔力由金、木、水、火、土、光、暗构成。雷、风、冰、炎、圣、时空等术式是复合或高阶表现。

### 4.2 七宗罪与罪兽

堕神索拉恩曾试图吸收人类所有“错误欲望”，再以自己为唯一理性统治世界。结果七种欲望与七律结合，形成七颗罪核和七只魔王级罪兽。罪兽并非完全由恶意构成，其中部分仍保留守护本能，玩家可以净化而非只击杀。

### 4.3 五心与双印

五颗世界之心分别是神圣、黑暗、冰、火、龙之心；金国与木国没有世界之心，而持有金衡圣印与翠根圣印。五心负责提供能量和见证，双印负责限制能量分配。七件遗物共同构成封住堕神的“七重锁”。

### 4.4 纯结

纯结不是第八元素，也不是所谓“绝对纯洁”。它是一个关系结构：七个不同意志在不被抹平、不互相占有的情况下仍愿意连接。伊芙琳拥有天然纯结资质，亚克则能提供七律接口；只有两人都拒绝成为祭品，纯结才成立。

## 5. 反派真相

### 表面真相

赛勒斯·莫尔坎是一名黑魔法师和邪教首领，绑架高共鸣者、进行献祭，并派魔兽阻挠七国合作。

### 中层真相

莫尔坎故意留下五心与双印线索。只有拥有七律低阶适性的亚克，才能安全取出七件封锁遗物。队伍每取得一件，封印就会暂时松动，蚀宴会便收集逸散的罪律。

### 深层真相

莫尔坎是圣教失落主神索拉恩的复活容器。数百年前，索拉恩认为自由意志必然制造痛苦，于是要吸收所有人的欲望、替所有人决定正确生活。晨星女神阿斯缇雅和七位古代守誓者将祂封印，圣教后世却因羞耻与权力需要，把主神堕落史彻底抹去。

### 最终真相

索拉恩不需要简单“复活身体”。祂需要七国再次选择同样的错误：垄断、比较、停滞、报复、吞噬、独断和占有。当七国主动重演七罪，祂就能证明“人类不配拥有选择”，并以此完成神格复归。玩家真正要击败的不是一具身体，而是这套逻辑。

## 8. 第50–100章的小分支设计

### 8.1 分支原则

小分支不制造七套完全不同的主线，以免制作量失控。它们改变以下四类内容：

1. 地区状态与终章援军；
2. 女主个人成长与隐藏爱慕／执念；
3. Boss阶段和真解法；
4. 101–103章资格。

## 9. 玩家选择的四种类型

### 9.1 政治选择

决定七国制度如何改变，例如技术公开、教团监督、龙族记忆保管和矿脉配给。

### 9.2 关系选择

决定是否诚实、是否尊重拒绝、是否处理多线暧昧和嫉妒。甜言蜜语不是万能答案，有时明确说“不”反而增加信赖。

### 9.3 解法选择

Boss可以被击杀、净化、解除罪核、说服或封存。高理解度解法能获得真共鸣，粗暴击杀则获得更快战利品和更高罪蚀。

### 9.4 自我定义选择

亚克是否接受“七属性容器”“救世主”“丈夫”“王”或“祭品”等他人赋予的身份。终章要求玩家明确哪些称呼是自愿选择，哪些只是功能。

## 10. 结局框架

### 10.1 第101章｜一心婚约（好结局）

玩家选择一位满足条件的女主。主线结束三年后，两人在对应国家或共同建立的新城举行婚礼。其余女主保留完整事业与友情，不因未被选择而被贬低。八位角色各有独立单人结局模块。

基本条件：

- 目标角色隐藏爱慕 `LOVE 90–99`；
- `TRUST ≥ 75`、`INTIMACY ≥ 60`、`BOUNDARY_STABILITY ≥ 70`；
- `SELFHOOD ≥ 65`、`OATH_STAGE = 3`；
- 个人任务完成，没有未解决的重大欺骗或边界侵犯；
- 玩家在第94章明确选择单人关系。

### 10.2 第102章｜三冠共誓（完美大结局）

玩家从八位女主中选择三位结婚。艾瑟兰允许多人婚姻，但必须完成三人关系协商，不把任何人当附属或“默认同意”。婚礼发生在终章后三年，并由三位女主共同设计生活、职责、居所和私人边界。

基本条件：

- 五心与双印均达真共鸣，伊芙琳未被献祭；
- 七位罪律女主的个人罪蚀均低于60，至少五个国家完成地区救援；
- 八位女主个人主线全部完成；
- 三位候选各自 `LOVE 90–99`、`TRUST ≥ 80`、`INTIMACY ≥ 65`；
- 三位候选各自 `BOUNDARY_STABILITY ≥ 75`、`SELFHOOD ≥ 75`、`OATH_STAGE = 3`；
- 三对女主之间的 `PAIR_ACCEPTANCE ≥ 70`；
- `TEAM_HONESTY ≥ 75`、`PURE_BOND ≥ 80`；
- 第94–96章完成三方知情议约，没有隐瞒承诺；第100章选择七国共同托管。

系统上支持任意三人组合。为控制文本量，结局采用“八个个人婚后模块＋二十八组两两关系模块＋五种共同家庭模板”动态组合，而不是手写五十六条完全独立路线。

### 10.3 第103章A｜绯月独占（病爱结局）

某位女主隐藏爱慕达到100，同时 `OBSESSION ≥ 85`、`JEALOUSY ≥ 80`、`BOUNDARY_STABILITY < 45`、`SELFHOOD < 55`，且关系危机未修复。玩家长期纵容她排斥他人、隐瞒多线关系，或在第100章把契约控制权交给她。她最终把“爱”理解为只剩两个人的世界，并杀死或永久封印其他竞争者。

该结局以心理恐怖和非血腥演出呈现，明确是关系失败与罪律侵蚀的结果，不作为甜蜜奖励。八位女主各有不同的病爱表现，但共同主题是“把选择变成所有权”。

### 10.4 第103章B｜七罪吞冠（最坏结局）

至少五位罪律女主的个人罪蚀达到80、`PURE_BOND < 40`、`WORLD_FRACTURE ≥ 80`，并且伊芙琳被当作祭品或亚克接受成为唯一容器。七罪先后吞噬其七属性，索拉恩借他的身体成为新的黯冠神。八位女主可能成为七国傀儡、封印残响或反抗者。最终画面是亚克仍能听见她们的声音，却再也无法决定自己是否回应。

## 11. 内容语气

主线采用自然、易读的现代中文。国家礼仪、龙族与圣教角色可更正式，但不堆砌古风。轻松场景应持续存在：草莓蛋糕争夺、米娅装置事故、塞雷娜认真学习“先敲门”、奥菲利亚幼龙形态咬头、艾拉挑衅后反被将军、莉莉丝嘴硬接受摸头、芙蕾娅第一次被照顾时不知所措。

“靠近边界”的精彩来自：角色敢说危险的话、敢产生不体面的情绪、敢犯错，也必须允许其他人拒绝、反击、离开和要求修复。世界真实感来自后果，而不是把越界本身包装成浪漫。
