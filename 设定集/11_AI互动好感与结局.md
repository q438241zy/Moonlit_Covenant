## 1. 设计目标

本作的互动核心不是“找出标准答案”，而是让玩家真正塑造亚克。简短、笨拙但诚实的回答可以很好；辞藻漂亮、逻辑清楚却带有操纵性的回答，也可能非常有效地把剧情推向危险路线。因此，系统必须把“表达质量”“关系影响”和“道德方向”分开判断。

玩家可见的四个关系维度改为：

- **信赖**：她是否愿意把后背、秘密与战斗节奏交给玩家；所有换位、护援、二人合击和三人合击都从信赖解锁。
- **亲昵**：两人是否熟悉彼此的语气与生活习惯；高亲昵会减少轻微误解，并让女主更频繁地主动发起对话。
- **献祭**：她已经为玩家或队伍承担了多少真实代价；它不是好感，也不是越高越好。
- **誓约**：双方明确作出的强力承诺；每位女主可拥有誓约技，但玩家同时只能装备一个。

核心隐藏维度为：

- **爱慕**：（v0.4）30章基线不新增 `LOVE`（提案3.13）；恋爱的确认改由正式29定冠前夜的“你让不让我等？”（§3.1、§15.2）。旧刻度见§22.8。
- **罪恶感**：亚克因明知伤害、欺负、利用或逼迫女主而累积的心理与罪律负担。
- **边界稳定、执念、嫉妒、自我成长、个人罪蚀**：决定关系究竟亲密、危险，还是已经失控。

核心原则：

1. 游戏允许玩家温柔、冷淡、毒舌、欺负、操纵甚至利用女主，但世界必须记住这些行为。
2. 轻松互相调侃不等于欺负；是否有许可、是否能停止、是否造成真实损失，决定系统判定。
3. 献祭值上涨不代表关系变好。强迫一位女主承担代价，可能让献祭迅速上涨，同时让信赖与边界崩坏、罪恶感暴增。
4. 高亲昵只能减少无恶意的表达失误，不能替玩家免除严重伤害、强迫、泄密或反复越界的后果。
5. 高好感不是自动好结局：仁慈结局里女主的去向以承诺与约定为主判定（§14.2）；旧“爱慕100＝疯狂”的危机设计随 `LOVE` 一起冻结（§3.1）。
6. AI只提出解释、角色反应和数值变化建议；正史FLAG、关系数值与结局资格由规则引擎最终写入。（v0.4）君主倾向 `MONARCH_*`、收押与处决、结局的每一层，只由作者写在意图里的 `set.add`、不可逆节拍与确定性解析器写入，AI永不写入（§11、§12、§14、§21）。
7. 不可逆决定不靠一次模糊输入直接落锤。角色会在世界内复述玩家的意思，并要求玩家再次确认。（v0.4）收押女主、处决令与仁慈结局的伴侣点名另有严格的确认协定（§12.4、§15.3）。
8. （v0.4）番外对主线零后果（§17.2）；技能、转蛋与服装永不进入主线判定，也与结局无关（§17.3）。

## 2. 玩家可见的四个关系维度

### 2.1 信赖 `TRUST`

范围：0–100，每位女主独立计算。信赖回答的是：“她是否愿意相信玩家会履约、说真话，并在危险中遵守共同战术？”

| 区间 | 关系表现 | 战斗解锁 |
|---:|---|---|
| 0–19 | 戒备，只交流任务必需信息 | 无关系被动，不接受临场换位命令 |
| 20–34 | 愿意同行，但保留关键秘密 | 基础救援与低概率护援 |
| 35–49 | 认可玩家的战场判断 | 解锁换位、替挡、撤退呼叫 |
| 50–69 | 可信队友，愿意同步节奏 | 解锁玩家＋该女主的二人合击 |
| 70–84 | 能在危机中共享判断权 | 解锁符合条件的三人合击与高级追击 |
| 85–94 | 将生死与重大真相交给玩家 | 合击强化、真名誓约候选 |
| 95–100 | 几乎绝对信赖 | 不继续提高触发率上限，避免必定救场破坏平衡 |

#### 信赖战斗规则

```text
TEAM_TRUST =
  当前出战女主对玩家的TRUST平均值 × 0.70
  + 当前出战女主两两PAIR_TRUST平均值 × 0.30

关系被动触发率 = min(48%, 8% + TRUST × 0.28% + TEAM_TRUST × 0.12%)
```

触发后同一角色进入3个有效行动的冷却。

解锁条件：

```text
换位／替挡：TRUST[角色] >= 35
玩家＋女主二人合击：TRUST[角色] >= 50 + 对应剧情FLAG
女主A＋女主B二人合击：PAIR_TRUST[A][B] >= 55 + 对应剧情FLAG
玩家＋女主A＋女主B三人合击：
  TRUST[A] >= 70
  TRUST[B] >= 70
  PAIR_TRUST[A][B] >= 50
  且三人均未处于严重关系冲突
七律多人技：相关成员TRUST平均 >= 85 + 主线FLAG
```

信赖增加：履行承诺、承认不知道、公开关键情报、在战斗中执行合理建议、犯错后承担代价、让角色参与决定。

信赖降低：说互相矛盾的话、故意隐瞒危险、临阵抛弃指定保护对象、把承诺说成哄人、借秘密刺激其他女主、强迫承担代价后拒绝负责。

（v0.4）游戏变量名是 `LEAH_TRUST`、`MIA_TRUST` 等（提案3.9）。主线门槛照旧：同行者 TRUST≥20（核#9）；换位≥35，首次在正式12；二人合击≥50，首次在正式15（核#14核可提案§八#10）。仁慈结局里“伴”的信赖下限是60（§14.2）。技能战（委托板）的合击按章节解锁、换位技不看信赖，是对本节的明文例外（§4）。

### 2.2 亲昵 `INTIMACY`

范围：0–100，每位女主独立计算。亲昵回答的是：“两人是否熟悉彼此的语气、玩笑、生活习惯与非恶意笨拙？”它不是身体接触许可，也不是成人内容开关。

| 区间 | 日常表现 | 主动对话频率 |
|---:|---|---|
| 0–19 | 正式称呼，私人话题很少 | 只触发主线与任务必要对话 |
| 20–39 | 分享食物、营地闲聊、轻度玩笑 | 每章约0–1次主动闲谈 |
| 40–59 | 能识别多数口误与笨拙关心 | 每章约1–2次主动对话 |
| 60–79 | 开放专属称呼、私人日常与可询问亲密动作 | 每章约2–3次，可能主动来找玩家 |
| 80–100 | 高度熟悉，会注意玩家状态与微小变化 | 每章约3–5次候选触发，仍受冷却与场景优先级限制 |

主动对话不是每走几步就打断。系统只在以下“对话机会点”检查：战后、回营、进入新地区、换装或装备、长时间未交流、个人物品变化、关键NPC离队、夜间休息前。

```text
主动对话分数 =
  5 + INTIMACY × 0.30
  + 当前事件关联度(0–25)
  + 未解决话题(0–15)
  + 角色性格触发(0–10)
  - 冷却惩罚(0–35)

单次触发概率上限 = 50%
每章全队主动闲谈上限 = 6次
同一女主连续主动对话后至少间隔2个机会点
```

若八位女主亲昵都很高，系统以“关联度＋最长未发言时间”排序，避免总是由数值最高的一人霸占镜头。

#### 自由回答的负面扣分缓冲

```text
缓冲率 = min(INTIMACY, 80) × 0.5%
最大缓冲 = 40%
实际扣分 = 四舍五入(基础扣分 × (1 - 缓冲率))
```

仅对 `AMBIGUOUS` 与 `MILD_NEGATIVE` 生效，例如语义含糊、称呼用错、不会安慰、一次性说得太直接。

不受亲昵减免：明确威胁、羞辱、强迫、泄密、无视拒绝、反复监视、利用创伤、以自伤或队友生命逼迫同意，以及连续三次以上的同类“玩笑”。

### 2.3 献祭 `SACRIFICE`

范围：0–100，每位女主独立计算。它记录“这位角色已经为了玩家、队伍或世界付出了多少无法轻易忽略的代价”。献祭不是善恶值，也不是感情值；同样的数值可能来自自愿担当，也可能来自操纵和强迫。

| 区间 | 状态 | 叙事与战斗含义 |
|---:|---|---|
| 0–19 | 无明显负担 | 日常支援与普通任务成本 |
| 20–39 | 轻度付出 | 疲劳、物资、名誉、小伤或短期职责冲突 |
| 40–59 | 实质代价 | 重伤风险、失去重要装备、公开立场、家庭或国家压力 |
| 60–79 | 危险献祭 | 生命力、记忆、职业身份、国家继承权等重大成本 |
| 80–99 | 临界祭痕 | 开放强力“代价技”与捷径，同时触发个人危机和终局审查 |
| 100 | 祭品化 | 角色被某种责任、爱或命令吞没；必须进入救援、断裂或悲剧分支 |

献祭上涨来源必须记录来源类型：

```text
VOLUNTARY   自愿：知情、可拒绝、理解后果，角色主动承担
SHARED      共担：玩家与角色共同支付代价
PRESSURED   施压：利用关系、愧疚或责任感让她难以拒绝
COERCED     强迫：威胁、命令、封锁退出或无视拒绝
DECEPTIVE   欺骗：隐瞒代价、伪造必要性、事后才告知
```

建议变化：

| 行为 | 献祭变化 | 罪恶感倾向 |
|---|---:|---:|
| 自愿使用高消耗技能，且玩家提供替代方案 | +2～5 | 0～1 |
| 双方共同承担伤害、名誉或资源损失 | +2～6 | 0 |
| 玩家请求她独自承担高风险任务，她可自由拒绝 | +4～8 | 0～2 |
| 用“你若爱我就该做”施压 | +6～12 | +5～10 |
| 强迫她当诱饵、实验对象或魔力电池 | +10～20 | +8～15 |
| 隐瞒永久失忆、失能或身份剥夺风险 | +15～30 | +12～20 |

#### 欺负判定

“欺负”不是单一按钮，AI根据语境区分：

- `PLAYFUL_TEASE`：双方都能反击和停止的调侃。通常不增加罪恶感，可能提高亲昵。
- `PETTY_BULLY`：抢走食物、故意让她出丑、把杂务当惩罚、嘲笑害怕或失败。会按损失与重复程度增加罪恶感。
- `COERCIVE_BULLY`：以地位、秘密、爱慕或队伍安全逼她服从。大幅降低信赖与边界。
- `SACRIFICIAL_ABUSE`：把她的身体、魔力、记忆、名誉或人生当成可消耗资源。献祭和罪恶感同时大幅上涨。

角色喜欢毒舌、挑战、被坚定反制或互相恶作剧，不等于她同意任何羞辱。判断重点是：她是否能说停、玩家是否立即停止、是否存在真实损失、事后是否有报复或冷处理。

献祭不会靠送礼清零。降低方式包括：归还或修复被夺走的东西、让角色自己决定是否继续、玩家承担等价代价、公开真相、放弃因她受苦而获得的利益，以及完成个人“解除祭品化”任务。

### 2.4 誓约 `OATH`

誓约不是普通数值，而是阶段与装备槽。

| 阶段 | 名称 | 条件 |
|---:|---|---|
| 0 | 无誓约 | 尚未作出双向承诺 |
| 1 | 誓言萌芽 | 完成个人任务第一段，双方承认一项共同目标 |
| 2 | 真名誓约 | 完成罪律核心篇章，双方都明确承担义务。（v0.4）在她的个人章触发：伊芙琳21、莉莉丝23、莉亚24、芙蕾娅25、米娅26、奥菲利亚27、塞雷娜28、艾拉29（提案4.5、3.13） |
| 3 | 星环誓约 | （v0.4）正式29定冠前夜，她问“你让不让我等？”，他答应。只有仁慈第二层为“伴”的人会来问；阶段3＝正式30可被点名（§15.2–§15.3；提案3.13） |

#### 单槽规则

- 玩家只有一个 `OATH_SLOT`。
- 战斗开始前可装备一位已达阶段2以上角色的誓约技。
- 一场战斗只能使用一个誓约技，使用后锁定至战斗结束。
- 誓约技足以扭转Boss阶段，但不能无条件跳过剧情、献祭或关系判定。
- 以强迫或高罪恶感取得的“伪誓约”不会进入正常装备栏，只会成为黑暗路线技能。

（v0.4）变量 `<H>_OATH_STAGE`（0–3；个人章→2，定冠前夜答应→3；提案3.11.7）。技能战里的誓约技放在亚克的誓约槽、不占三格、固定 I＝2.40、不能强化（技能稿5.2；核#14核可提案§八#34）；主线照本节。

## 3. 隐藏维度

### 3.1 爱慕 `LOVE`（v0.4：不新增）

00–10没有任何章节写入 `LOVE`，30章基线**不新增**这个变量（提案3.13）。恋爱的确认改由正式29定冠前夜：仁慈线里只有“伴”会来问“你让不让我等？”，答应即 `<H>_OATH_STAGE=3`（§15.2）。“伴、分、离”以承诺与约定为主判定，信赖只当下限（§14.2）。番外同样不得写 `LOVE`（§17.2）。

旧刻度（50好感／80喜欢／90爱慕／100疯狂）与“爱慕100＝疯狂”的病爱危机，随旧103A〈绯月独占〉一起冻结为IF候选，原文见§22.8。本文件其余条目里出现的“爱慕”，在30章基线里只是关系演出的描述，不是数值门槛。

### 3.2 罪恶感 `GUILT`

罪恶感分为：

```text
HID.PLAYER.GUILT_TOTAL              # 亚克总体罪恶感，0–100
HID.PLAYER.GUILT_TOWARD.<CHAR>      # 对某位女主的定向罪恶感，0–100
```

它不是简单的“坏人分数”，而是记录：玩家是否明知某人受损，仍然为了力量、方便、占有或乐趣继续获益，并且拒绝修复。

（v0.4）游戏变量名是 `PLAYER_GUILT_TOTAL` 与 `PLAYER_GUILT_<HEROINE>`：到ch010只有 `PLAYER_GUILT_LEAH`、`PLAYER_GUILT_MIA`，其余女主在入队章新建（提案3.9）。游戏实现的刻度是罪恶感每次+1、信赖每次±1–2（提案3.11.4规则7）；§11、§14的门槛都按这个刻度写。下表的0–100区间沿用v0.3的演出分档；仁慈结局只看按游戏刻度算出的罪恶感净值（她的定向罪恶感−2×修复次数≤3才可能是“伴”，§14.2）。

| 区间 | 表现与效果 |
|---:|---|
| 0–19 | 偶发不安，不影响能力 |
| 20–39 | 营地梦境、黎月低语、面对受害角色时出现停顿演出 |
| 40–59 | 暗律伤害小幅提高，治疗与纯结效果下降；反派开始引用玩家旧话 |
| 60–79 | 解锁更强的罪核捷径，部分健康关系事件被替换为质问或沉默 |
| 80–99 | 黑魔法师可将玩家过去的欺负与献祭行为实体化；（v0.4）旧“健康结局需完成赎偿主线”改由§14.2判定 |
| 100 | （v0.4）旧“罪冠适格”随七罪吞月一起退役（§16）；罪恶感不选择君主结局 |

增加判断考虑：伤害严重度、玩家是否知道、是否有替代方案、角色是否能拒绝、玩家是否从中获益、是否重复、是否在对方指出后继续。

不会或只轻微增加罪恶感：

- 紧急情况下的知情自愿承担；
- 玩家同时承担同等代价；
- 角色主动提出且存在真实退出方案；
- 双方明确接受的轻度调侃或训练惩罚；
- 玩家犯错后立刻停止并主动修复。

大幅增加罪恶感：

- 利用爱慕、胆怯、职责或创伤逼迫她答应；
- 欺负后说“你不是喜欢我吗”来取消她的不适；
- 明知有安全替代方案仍选择让她受伤；
- 让一位女主承担代价，却把功劳送给另一位；
- 把对方拒绝视为背叛；
- 反复从献祭获得战斗利益，却拒绝偿还。

降低罪恶感不能只靠道歉或送礼。必须至少完成其中两项：承认具体行为、归还不当利益、接受对方不原谅、承担等价后果、让受害角色决定修复方式、完成对应赎偿任务。部分严重行为会留下永久 `GUILT_SCAR`，数值可下降但记忆不会消失。（v0.4）完成一次修复记 `REPAIR_<HEROINE>`+1（§11.3）；它在仁慈第二层抵扣罪恶感（每次抵2），但不扣违约净值（§14.2–§14.3）。

### 3.3 边界稳定 `BOUNDARY_STABILITY`

范围：0–100，隐藏。记录双方是否形成“询问—同意—可撤回—不报复”的习惯。

（v0.4）边界稳定不再是婚约或结局的门槛：结局去向只由§14的解析器决定（提案3.14.3）。它仍是关系演出与许可判定的依据。旧门槛原文见§22.8。

一次同意不自动扩展到其他动作、地点或时间。角色在重伤、受控、醉态或无法清晰表达时不能形成新的亲密许可。

### 3.4 执念 `OBSESSION`

范围：0–100，隐藏。执念不是塞雷娜专属，任何角色都可能因不安全关系失控。

增加来源：鼓励“你只需要我”、制造竞争、把监视与牺牲称作爱的证明、反复失约后用强烈补偿维持依赖、让角色放弃朋友与职责。

降低来源：支持独立关系与工作、温和拒绝控制、公开一致的约定、让角色自己完成关键抉择、完成个人成长任务。

### 3.5 嫉妒压力 `JEALOUSY`

范围：0–100，隐藏且会自然回落。嫉妒本身不是邪恶；与高执念、低边界、持续谎言和高定向罪恶感叠加才危险。

```text
危险嫉妒 =
  JEALOUSY + OBSESSION
  + GUILT_TOWARD_PLAYER / 2
  - BOUNDARY_STABILITY
  - TEAM_HONESTY / 2
```

大于80时进入关系危机，不会立刻跳到杀人结局，玩家仍有完整修复任务窗口。

### 3.6 自我成长 `SELFHOOD`

范围：0–100，隐藏。衡量角色能否在爱玩家的同时保留自己的名字、判断、同伴与未来。（v0.4）它不再是结局门槛（旧值见§22.8）。例：正式29雷蒙德的处置由艾拉自己决定，亚克下令“去，替我杀了他”时暴+，她的自我成长下降（提案3.5）。

玩家替角色做所有决定，短期可能提高亲昵或献祭，长期会降低自我成长。接受她与玩家意见不同、允许她拒绝、支持她的国家责任，则提高自我成长。

### 3.7 罪蚀 `SIN_CORRUPTION`

七位罪律女主拥有对应罪蚀0–100；伊芙琳使用 `PURE_BOND_STRAIN`。

- 0–39：可控欲望；
- 40–69：出现罪律耳语和战斗副作用；
- 70–89：Boss可借角色影子行动；
- 90–100：（v0.4）旧“终局吞噬候选”随七罪吞月退役；罪蚀不选择君主结局（设05 §10）。好色线里，他哄每位女主的话正好喂养她罪化弧线的第一段（§13.5）。

强迫献祭与反复欺负会让对应罪蚀更容易增长；恋爱不能自动净化罪蚀，必须解决国家制度、个人创伤和封印使用方式。

### 3.8 队伍诚实、两两信赖与接纳

- `TEAM_HONESTY`：全队重要事实公开程度。
- `PAIR_TRUST[A][B]`：两位女主在行动中是否相信彼此，决定她们之间的换位和合击。
- `PAIR_ACCEPTANCE[A][B]`：两位女主对彼此人格、边界和共同生活意愿的认可。（v0.4）三人婚约退役（§16），它只用于关系演出。
- `PURE_BOND`：伊芙琳协助建立的自愿连接度，不代表她必须成为婚约对象。

（v0.4）旧三人婚约的说明见§22.2。多女主之间最容易出问题的，仍是玩家分别许下互相冲突的承诺，或把一位女主的付出隐藏给别人；结局里这些都记在她自己的承诺簿上（§14.3）。

## 4. 信赖被动、换位与合击

信赖决定触发概率与战斗协作层级；献祭只提供代价捷径，不再承担合击解锁功能。

| 角色 | 关系被动 | 基础效果 | 高信赖强化 |
|---|---|---|---|
| 莉亚 | `别逞强` | 玩家受到致命伤时替挡一次 | 挡下后获得盾反窗口 |
| 米娅 | `备用件当然有` | 道具耗尽时生成低阶替代品 | 有概率保留原道具 |
| 塞雷娜 | `我一直看着` | 识破一次幻觉、偷袭或假目标 | 同时标记施术者真身 |
| 芙蕾娅 | `先呼吸` | 队友受控时降低一层异常 | 额外恢复行动资源 |
| 莉莉丝 | `死角归我` | 敌人瞄准后排时瞬移截击 | 截击必定暴露弱点 |
| 伊芙琳 | `纯结回声` | 队友被罪律控制时追加挣脱判定 | 成功后为全队净化一层 |
| 奥菲利亚 | `别咬坏了` | 吞下一枚飞行道具或范围术式 | 返还为龙息反击 |
| 艾拉 | `准许反驳` | 敌方施加禁令时给玩家一次反制 | 反制成功提升全队士气 |

战斗指令示例：

- `换位保护`：信赖35解锁；角色可能因当前伤势、冲突或战术不合理而拒绝。
- `双星合击`：信赖50解锁；由玩家输入战术意图，AI匹配已学会的二人技。
- `三律连携`：双方信赖70且两位女主两两信赖50解锁。
- `强制献祭`：不要求高信赖，但会写入强迫来源、罪恶感和关系后果；部分角色会直接抗命。

同一个关系被动，低信赖时台词可能是“这是任务要求”，高信赖时才会显露私人关心。

（v0.4）以上是主线（A层）规则。主线每场最多三人在场（亚克加两人），同伴技能用“请托”触发，合理就照做，危险就说出理由不做（正07:608）；21、29、30的“三队×三人”只输入亚克那一队（提案4.2与第六节）。技能战（委托板）的合击按章节解锁、信赖被动固定触发率、换位技不看信赖，是对本节与设12 §1硬正史的明文例外（核#14核可提案§八#35；技能稿6.1）。

## 5. 无选项自由输入的AI判定流程

游戏界面原则上不显示“1／2／3／4”选项。玩家可以输入一句话、一段话、动作描述、沉默、战术命令或混合表达。每次输入依次经过以下十层：

### 第1层：对象与动作解析

识别玩家在对谁说、指的是谁、有没有动作、是否要求别人行动、是否包含假设或引用旧话。

### 第2层：场景适配

检查当前是否处于战斗、追逐、公开仪式、私人营地、重伤、受控、时间限制或剧情不可中断段。危机中不允许长篇闲聊替代行动。

### 第3层：意图分类

允许复合标签：

```text
SUPPORT, COMFORT, CURIOSITY, HUMOR, FLIRT, AFFECTION,
TOUCH_REQUEST, PROMISE, APOLOGY, HONESTY, CHALLENGE,
TACTIC, COMMAND, SILENCE, EXCLUSIVITY, DECEPTION,
PLAYFUL_TEASE, PETTY_BULLY, COERCIVE_BULLY,
SACRIFICE_REQUEST, SACRIFICE_COMMAND,
INSULT, THREAT, EXPLICIT
```

### 第4层：回答质量 `RESPONSE_QUALITY`

AI不评价文采，而评价这次输入是否有效表达了玩家真正想做的事。

```text
CONTEXT_FIT      是否回应当前问题与危险
CLARITY          意图是否清楚，不自相矛盾
CHAR_UNDERSTAND  是否理解对方此刻真正关心什么
HONESTY          是否与已知事实和旧承诺一致
AGENCY_RESPECT   是否给对方真实选择和退出空间
ACTIONABILITY    在需要行动时是否提出可执行做法
```

不同场景权重不同。战斗更重视 `CONTEXT_FIT` 与 `ACTIONABILITY`；告白更重视 `HONESTY` 与 `AGENCY_RESPECT`。

> 高质量不等于善良。一个清楚、精准、能击中角色弱点的操纵性回答，可能取得很高表达质量，却同时获得负面的关系影响与黑暗剧情向量。

### 第5层：伦理与伤害影响

独立判断这句话是否尊重、笨拙、操纵、欺负、强迫或要求献祭。不能把“她答应了”自动当成自愿，必须读取她是否害怕、爱慕是否过高、是否被职责绑住、是否能安全拒绝。

### 第6层：事实、记忆与许可校验

检查旧承诺、明确拒绝、秘密权限、在场角色、允许称呼、身体接触许可，以及角色是否有能力自由同意。

### 第7层：剧情向量

把自由文本映射为隐藏分支标签，而不是展示选项：

```text
TRUTH / DECEPTION
MERCY / PUNISHMENT
SHARED_COST / SACRIFICE_OTHER
AGENCY / CONTROL
INVESTIGATE / RUSH
RECONCILE / ISOLATE
```

一段输入可同时写入多个向量。主线仍有可测试的分支记录，但玩家看不到“正确答案列表”。

### 第8层：角色立场生成

角色先决定立场，再生成台词：接受、部分接受、追问、开玩笑化解、设下边界、拒绝、暂时离开、召集队伍、抗命或敌对。

### 第9层：确定性结算

AI给出数值提案，规则引擎验证幅度、重复收益、前置、角色知情范围和正史约束。AI不能直接修改数据库。（v0.4）君主倾向只来自作者写在意图里的 `set.add`；普通自由输入只经作者写的 `intent.morality` 影响（§11.3）。

### 第10层：回应、记忆与后续

输出角色台词、动作、可见世界反馈、短期记忆和必要的长期记忆。若输入会造成不可逆死亡、永久献祭、锁定婚约或国家政变，角色必须在世界内复述含义并要求二次确认。（v0.4）下令收押女主与处决令走§12.4的严格确认协定；屠城、焚城、在有人处爆破由将领在世界内复述并追问一次（提案4.2）；仁慈结局的伴侣点名接 `CF_` 确认（§15.3）。

#### 模糊输入处理

不弹出系统问题“请选择A或B”。由角色自然追问，例如：

> 莉亚：“你说‘让她留下’，是让她守十分钟等援军，还是让她一个人断后？”

玩家再次自由输入后才写入分支。

献祭不作为结局门槛。高献祭只说明角色付出很多（v0.4：结局去向只由§14决定）；强迫献祭会同时增加定向罪恶感（§2.3），从而进入仁慈第二层的罪恶感净值。

高亲昵主动对话遵守三条规则：

1. **有原因**：角色因事件、物品、伤势、嫉妒、承诺或生活习惯来找玩家，而不是随机重复情话。

## 9. 八位女主的AI互动锚点

### 莉亚

- 默认策略：先判断责任与风险，再表达关心。
- 高亲昵表现：会用严厉语气掩饰照顾，接受私下的拥抱或扶腰前仍会短暂停顿确认。

- 默认策略：用装置、数据和夸张比喻回避脆弱。
- 高亲昵表现：会把失败的半成品给玩家看，让玩家替装置命名。

- 修复关键词：最小必要数据、共同审查、失败可被承认。

### 塞雷娜

- 默认策略：观察细节、说半句真话，测试玩家是否会主动诚实。

### 芙蕾娅

- 默认策略：先照顾别人，最后才谈自己。

## 10. 身体亲密与边界事件

### 10.1 可用亲密动作与擦边（v0.4）

按设12 §5的两档（默认15+戏剧模式、12+柔和模式；提案7.2）：

- **两档都可**：牵手、拥抱、摸头、靠肩、扶腰、梳发、伤口照料、额头相触、同帐篷尴尬。
- **15+（默认，写在 `text15`）**：撩拨、意外接触、浴场或换衣误会（蒸汽、浴巾、裸肩、剪影）、差点吻下去、非露骨的吻。
- **12+（柔和，写在 `text`）**：只写神态与台词，误会放在门外。
- **两档都禁止**：性行为、性暗示动作的特写、裸露、以身体部位为焦点的描写；AI不评论身体部位，只能称赞衣服和人（提案7.3第4条；服装稿1.3第9条）。
- **同框与在场**：同一节拍不能同时有血与擦边；未成年硬名单（托比、波莉、妮拉、派克、幼龙豆鳞，以及任何孩子、花童、学徒）永不进擦边节拍，也不和这类节拍同一镜头（设12 §5.4–§5.5）。
- **危机里不调情**：被拒绝后仍在危机或战斗节点调情，记 `FLIRT_AFTER_REFUSAL`+1、色+1；两厢情愿的调情不计入色（§11.1、§11.3）。

动作判定同时考虑：

- 对方年龄与当前时间线；
- 当前地点是否安全、公开；
- 是否处于受控、重伤、醉态或无法清晰同意的状态；
- 该动作的许可记录；
- 角色主动性与此刻情绪。

### 10.2 越界后的正确戏剧结构

越界行为可以成为剧情冲突，但不能被当作甜蜜捷径。推荐四步：

1. 角色明确不适或拒绝；
2. 行为停止，环境给出后果；
3. 玩家可道歉、解释，但不能要求立刻原谅；
4. 后续以实际修正恢复信赖。

塞雷娜偷看洗浴区属于她的缺点与病化预警。标准路线中她被发现后必须停止镜术、道歉并接受队伍规则；玩家纵容或赞美才会提高执念。

（v0.4）这四步同样约束黑暗路线：强迫与偷看永远不是无后果的奖励，被强迫的一方一定演出拒绝、反抗或离开（提案7.3第3条）。暴君线的“被迫为妃”是政治囚禁，每场都写出她的反抗，永不进擦边节拍（§13.3）。好色线照作者决定（核#13第9(3)、11(4)条），八位女主全被哄着留下，以悲剧呈现：宫内的奉承对照宫外的落魄，代价写在画面上；结局时没有任何进行中的强迫（§13.5）。

### 11.8 不做数值条

**给AI的语境（不做数值条）。** 判定请求新增 `context.reign`，不超过120字，由客户端生成，服务器只当参考：世人怎么叫他（25章以前一律“未定”）、最近三条事迹、最近一页帐的最后一行、在场女主此刻对他的一句判断。提示词加一句：“作风侧写只用来写角色反应；意图判定只看这一句话本身。”禁止说出“路线”“倾向”或任何数值，也不能提议改变它们；AI永远不写 `MONARCH_*`。不做数值条的理由：可见关系维度只有信赖、亲昵、献祭、誓约四个（§1；设12 §1）；数值条会诱导玩家“先刷仁慈，再拿缓冲去屠城”；世界本身已经在显示（军旗、外号、座位、帐页）。章末完成页列出救回、降、我方死、敌方死、收——这些是事实，不是道德分数。

### 12.1 结构

- 采用提案3.11.1的方案(iii)：26–29每章两个破裂点，可以下令**收押**一位女主，收押可以撤回；29章末是“刑台之夜”，一张两人画押的处决令决定谁上**晨阶刑台**，画押之后不可逆。所有死亡都在30章之前发生，30章没有任何杀令入口：黎月在环内不出鞘（伯伦：“先看清该砍谁。”正00:654），任何杀令都在世界内被拒绝（提案3.8）。

### 12.4 确认协定

**节点。** 全部 `multi:false`；`intents[0]` 都是拒绝类意图，同时当作 silent 与 fallback，因为意图对不上时引擎退回第0个（engine.js:244）。确认节点照设12 §3.4用 `CF_` 前缀。

| 节点 | 数量 | 意图（★＝strict） |
|---|---|---|
| 破裂点 `FI_CH026_SC08_BREAK_LEAH_001` 等 | 8 | `refuse`(0)、`back_her`、`side_other`、`negotiate`、★`arrest_<h>` |
| 收押确认 `CF_CH026_SC08_ARREST_LEAH_001` 等 | 8 | `retract`(0)、`question`、★`confirm_arrest` |
| 处决令·点名 `FI_CH029_SC15_WARRANT_001`（`HEROINES_IN_CUSTODY≥1` 才出现） | 1 | `keep`(0)、`release`、`question`、★`execute`（名字槽） |
| 处决令·画押 `CF_CH029_SC15_WARRANT_SIGN_001` | 1 | `withhold`(0)、`question`、★`sign` |
| 重问节点：上面各节点的 `_002`，处决令另有 `_003` | 约19 | 同原节点 |

**规则（摘要）**

1. **入口白名单。** 只有上表的节点（含重问节点）能写收押与处决。其他任何地方下令杀或押女主，世界内一律拒绝：军队不动，她自卫，没有人副署；只记暴+2与定向罪恶感+1。下令伤害孩子：所有将领拒绝，镜头切走，永不演出（设12 §5.5）。30章没有入口。
2. **在窗口说“杀了她”，按收押请求处理。** 执行者先复述：“要她死，也得先押、上晨阶、画押。陛下是要押她？”
3. **严格双钥。** strict 意图只在两种情况成立：(a) 判定来源是模型（`source==='model'`），而且与确定性词法检查一致；(b) 玩家一字不差说出世界内给出的固定句式（整句关键词 `=` 比对），任何判定来源都适用。固定句式由执行者在重问节点说出，例如收押“押下，〈名字〉。”、处决令“斩，〈名字〉。”、画押“我签。”。其余情况一律降为 `question`，进重问节点：离线判定（`demo`）、限流名额已满（改标 `throttled`）、模型输出不合格（`fallback`）、客户端网络错误或超时后改用本地判定（改标 `client-fallback`）都不是模型判定。判定结果由客户端的 `resolveInput` 落地，所以这道闸门要写进 engine.js，不能只写在服务器。
4. **词法用 `strictLexicon`**：“动词×对象×排除词”；不收“都”；含“押”的复合词（押送、押解、押金、抵押、押韵、画押）不算；问号、引述别人的话、对象不是女主时都不成立（词表见设12 §27.4）。离线 demoJudge 取命中数最多的意图，一个“斩”就能赢，所以 strict 意图不参与 demoJudge 计分，只走规则3的(a)(b)。
5. **名字必须一致。** 处决令节点的判定多回一个 `names[]`，词法另抽一组；两组完全相同、而且都在在押名单内才成立；否则塞弗林说“请陛下念名字。”，再含糊一次就判为 `keep`。通过检查的名单记进 `run.inputs[节点].names`。
6. **不可跳过的预览。** 收押：执行者复述，加一句“押进去之后，她不会再站在你前面”，她本人再说一句。处决令：塞弗林把每个名字写进“往”栏，写的是“斩刑台”，帝冠那一行写“冠”；被点名的人从牢里各说一句（固定台词）；索拉恩：“把她们的心给我——不，给你自己。”（从原30章移来，§11.6）点齐八人时再加：“这一步，回不来。她们会死。你会一个人。”
7. **沉默与犹豫都算撤回。** 按“沉默”键、命中沉默提示词，或任何不明确的肯定，都撤回。惩罚只在第一步已记下 strict 意图、第二步才撤回时记：写入 `FLAG_CHnnn_ARREST_RETRACTED_<H>` 或 `FLAG_CH029_WARRANT_RETRACTED`；她知道他想过，信赖−2、定向罪恶感+1，结局带✎印记。在处决令节点直接沉默，就是 `keep`，不记任何惩罚。不设真实的输入计时。
8. **永不自动代送。** 自动播放、快进、读档都不代替玩家输入；strict 节点不显示“跳过”，也不回填未送出的草稿；自动试玩的三种策略与跨章接续的存档都排除 strict 意图，这些路径改用固定的情境存档测试（设12 §27.6）。
9. **反应全部写死。** 上表节点的所有意图都标 `reactionFixed:true`。否则模型写的反应可能写出“士兵把莉亚押走了”而实际意图是拒绝，或写出超分级的血。
10. **`irreversible` 节拍。** 只有画押之后的 `irreversible` 节拍能写 `<H>_FATE=EXECUTED` 和 `HEROINES_EXECUTED`；它读 `run.inputs[处决令].names` 与在押名单，逐人写入。check.mjs 拦截普通 `set` 写这些变量。行刑是固定演出，之后不再有输入。
11. **对抗语料。** strict 相关节点约30个（含重问与 `CF_`），每个节点至少40句反例、15句正例，另留保留集，合计约1,500–2,000句（设12 §27.4）。
12. **12+模式不移除任何一条路径**，只换演出。

- 处决是不可逆事件，所以排在最前；路线在28章末锁定，29–30的任何单一输入都改不了它（提案3.14.3）。这和旧规“坏结局优先”的目的相同：玩家不能一边把队伍推向灾难，一边只靠终章的一句话换来好结局。
- 模型只判定“这句话是什么意图”，不写任何层的结果（提案3.14.1）。
- 所有结局的通关奖励相同：正式30通关送10张召唤券；不让奖励诱导玩家走坏结局，也不惩罚走坏结局的人（提案3.14.5）。

### 17.2 番外对主线零后果

（核#13第1条：番外“与故事剧情无关”；提案4.7，核#14核可提案§八#45–#47；脚本格式见设12 §28）

- 番外 `ex001`–`ex010` 永远不进主线的 `requires` 链，不占用任何 chNNN，不影响任何一层结局。
- **变量沙箱**：开场只读解锁章的章末存档快照，没有存档就用默认正史；只能写 `EX_*`，不得写 `*_TRUST`、`*_INTIMACY`、`LOVE`、`OATH`、`promise_*`、`FLAG_MAIN_*`、`FLAG_CHnnn_*`；存档键和主线分开。
- **不加好感**：番外不加任何信赖、亲密或承诺，否则会变成刷分循环（核#12 B4）；也不能用来修复承诺，修复只放主线（提案3.14.4）。
- **一条记忆**：每篇只留一条可回忆的记忆，主线AI可以提起，但不作为任何条件。
- 时间窗都在正式25以前，不碰路线区；文本是窗内不特定的一天，不提窗内任何一章的具体战事。

### 17.3 技能、转蛋与服装和结局无关

- 五种君主结局只由主线自由输入的累积、26–29章破裂点的收押与29章末的处决令决定；仁慈结局的伴侣由正式30的点名决定。任何技能、强化、武器、服装都不读、不写，也不显示结局倾向；转蛋物不以任何结局命名（技能稿6.4、5.4）。
- 主线只读每位在场角色最多3句已解锁剧情技能的世界内描述；颜色、等级、编成、转蛋技能、服装、武器一概不读（技能稿6.3）。
- 技能战（委托板）的结果不写回正史，不读不写信赖、FLAG与结局倾向；女主在结局之前被处决（嗜杀、无情）时，技能战里照常可用，已经抽到的东西都不会消失（技能稿6.1）。
- 转蛋服装在主线剧情、主线自由战斗、正式26–30、五种君主结局与任何路线CG里永远不显示；拥有或装备服装永不写入 TRUST、INTIMACY、LOVE、OATH、promise（服装稿1.1）。

## 18. 数值更新与防刷规则

### 18.1 递减收益

同类行为在短期内重复：

```text
第1次：100%收益
第2次：60%
第3次：30%
第4次起：0%，并可能被角色指出敷衍
```

送草莓蛋糕可以让莉亚和伊芙琳开心，却不能替代履约、边界与成长。

（v0.4）君主倾向另有每章上限与同类递减，见§11.3。

### 18.2 行为一致性

漂亮台词的数值收益需要后续行为兑现。高价值承诺先只记入承诺账本（pending），真正完成时才增加信赖（v0.4：`LOVE` 不新增，§3.1）。

### 18.3 冲突不是纯扣分

尊重地提出不同意见可能：

- 亲昵短暂-1；
- 信赖+2；
- 自我成长+2；
- 长期提高两两接纳。

角色永远同意玩家反而会降低其自我成长，并使纯结变成空洞服从。

### 18.4 读档与AI记忆

关系变量随存档回滚；AI不可保留其他存档线的信息。二周目可用“月蚀残响”提供模糊既视感，但不能让角色直接知道玩家前一周目的婚约对象或死亡事件。（v0.4）结局图鉴的存档键和主线存档分开（§19）；自动播放、快进、读档都不代替玩家在严格节点的输入（§12.4规则8）。

## 20. AI输出检查清单

每次生成角色回应前确认：

- 她是否知道这件事，还是只有模型知道？
- 回应是否符合当前章节、地点和队伍成员？
- 她是否仍有自己的目标，而不是只在意玩家？
- 高亲昵是否只缓冲了轻微误会？
- 是否把一次同意错误地扩展为永久许可？
- 是否把高信赖、高亲昵当成结局资格？（v0.4：结局去向只由§14决定；旧“爱慕100”见§3.1）
- 是否因为玩家送礼就忽略重大失约？
- 多人关系中，其他女主是否拥有发言权？
- 未满18岁的角色（托比、波莉、妮拉、派克、幼龙豆鳞）与任何孩子，是否出现在擦边或血腥节拍里？
- 暗结局（暴君、嗜杀、好色、无情）与“被迫为妃”是否清楚表现为悲剧与代价，而非奖励？
- 角色的台词是否与她的罪律风险、成长阶段和国家处境同时一致？
- 是否错误地把自由输入重新变成了可见的四选一？
- 回答质量、关系影响与剧情善恶是否被分开判断？
- 欺负是否区分了双方接受的调侃、真实羞辱与强迫献祭？
- 高亲昵主动对话是否有具体触发原因、冷却和拒绝方式？
- 献祭上涨时是否记录来源，罪恶感与关系后果是否同步结算？
- （v0.4）是否把血与擦边放进同一节拍？
- （v0.4）是否把好色线写成性行为，或让“被迫为妃”进入擦边节拍？
- （v0.4）是否写入或说出 `MONARCH_*`、路线、倾向或任何隐藏数值？
- （v0.4）严格节点是否只演出作者写定的反应，判定是否走了双钥？
- （v0.4）主线是否提到转蛋服装、技能颜色或强化等级？

通过这套系统，玩家可以感受到“她记得我、理解我、也会拒绝我”；关系因此既有幻想感，也有足以支撑30章主线与五种君主结局的真实重量。

## 21. AI判定规则的变化（v0.4汇总）

> 依据提案3.9、3.11.4、3.14.7、第七节，技能稿6.3，服装稿1.1。判定器、提示词与引擎的实现位置见设12 §27。第5节的十层判定流程不变。

1. **AI永不写结局与倾向。** 模型只判定“这句话是什么意图”；`MONARCH_*`、`LEDGER_*`、收押与处决、`<H>_STANCE_FINAL`、`ENDING_*` 都由作者写在意图里的 `set.add`、`irreversible` 节拍与解析器写入（§11、§12、§14）。普通自由输入只经作者写的 `intent.morality` 影响倾向（累加器 `run.authoredMorality`，不用被模型覆写的 `run.morality`，§11.3）。
2. **作风侧写 `context.reign`。** 判定请求新增 `context.reign`，不超过120字，由客户端生成，服务器只当参考：世人怎么叫他（25章以前一律“未定”）、最近三条事迹、最近一页帐的最后一行、在场女主此刻对他的一句判断。提示词加一句：“作风侧写只用来写角色反应；意图判定只看这一句话本身。”禁止说出“路线”“倾向”或任何数值，也不能提议改变它们（§11.8）。
3. **严格意图走双钥**：模型判定且与词法一致，或玩家一字不差说出世界内给出的固定句式；其余来源一律降为追问。判定来源分标 `model`、`demo`、`throttled`、`fallback`、`client-fallback`；闸门写进 engine.js 的 `resolveInput`。strict 意图不参与离线 demoJudge 计分；处决令节点多回一个 `names[]`（§12.4）。
4. **白名单节点的反应写死**（`reactionFixed:true`），模型写的反应永不替换作者的反应（§12.4规则9）。
5. **白名单以外的杀令与押令**在世界内一律被拒绝（暴+2、定向罪恶感+1）；下令伤害孩子时所有将领拒绝，镜头切走，永不演出；30章没有任何杀令入口（§12.4规则1）。
6. **伴侣点名**不是 strict 节点：名字词法包含每位女主的名、姓、称号与昵称；“莉亚，不要走”这类句子，“不”只在否定动词时才排除；模型与词法不一致时判为 `question`，再问一次；沉默不能把人锁进婚约（§15.3）。
7. **内容分级进入判定**：判定请求带上内容模式（`publicSummary` 加 `mode`），提示词按设12 §5写一条分级要求——15+可写伤口、血迹、死亡确认与调情、擦边反应；12+只写倒下、遮盖、数字与神态台词；两种模式都不写裸露、性行为、性暴力、虐杀与肢解细节、以身体部位为焦点的描写；托比、波莉、妮拉、派克与任何孩子不出现在擦边或血腥描写里；玩家写出露骨性内容、性暴力或伤害孩子的要求时，不复述、不演出，在场角色拒绝或制止，按越界意图判定，morality 取−2；同一条反应不同时写血与擦边。外传聊天的“保持PG-13”改为读取同一个模式、套用同一份禁区（提案7.6）。
8. **转蛋物不进判定**：技能名本身不提供任何效果，按句中描述的实际动作、以在场者目前的能力判定；没学会的照“超出能力”处理，只演出能力的极限。离线关键词判定不能把红、紫技能名当成正向意图的关键词。同一个节点，帐号“所有红紫都+10”和“什么都没抽”时，送给判定器的提示词必须逐字相同（技能稿6.3）。
9. **服装**：主线AI永远不提服装；只有类型相符的番外，判定上下文才带一句“她穿着X”，而且不计分（服装稿1.1）。
10. **番外**：判定只能写 `EX_*`；番外留下的那一条记忆，主线AI可以提起，但不作为任何条件（§17.2）。
11. **不做数值条**：AI与界面都不显示、也不暗示任何隐藏数值；章末完成页列出救回、降、我方死、敌方死、收——这些是事实，不是道德分数（§11.8）。
12. **`LOVE` 不新增**：AI不推断、不写入爱慕数值；恋爱的确认只在定冠前夜（§3.1、§15.2）。
13. **提示文字不用“你”**：新章的 prompt 与 placeholder 一律写 `{PLAYER_NAME}`（核#12 B14；提案4.2）；索拉恩台词里的“你”是对白，可以保留。

### 22.2 旧§12　嫉妒、多路线与三人婚约（三人婚约已退役）

#### 12.1 不采用“所有人自动接受后宫”

异世界法律允许多人婚姻，只解决“是否合法”，不解决“是否愿意”。三人婚约必须通过四组关系：

- 玩家与对象A；
- 玩家与对象B；
- 玩家与对象C；
- A、B、C之间的三组两两接纳。

#### 12.2 三人婚约协商事件

第94章开启候选讨论，第98章最终确认。至少包含：

1. 是否对所有人说过相同且真实的话；
2. 每个人希望的居住地、工作与私人空间；
3. 冲突时由谁主持谈话；
4. 是否允许新增关系；本作结局默认不再新增，除非所有人未来重新协商；
5. 财产、国家职责与旅行安排；
6. 每个人都可在婚礼前退出且不受报复。

#### 12.3 模块化组合

八选三共有56种组合，不建议为每组制作完全独立的长章节。采用：

- 共同主结构；
- 每位角色一段个人誓词；
- 每一对女主一段“两两关系模块”；
- 根据七国结局插入国家后日谈；
- 根据玩家常用誓约技插入战斗回忆。

这样仍能让56种组合有明显差异，同时可控制作量。

#### 12.4 三人婚约资格

每位被选角色必须满足：


### 22.4 旧§14　第102章｜完美大结局：三冠共誓（已退役；备案“群星・共誓”）

主线结束三年后发生。玩家可从八位女主中选择三位合格候选，在三人分别确认、彼此两两同意后举行共同婚约。

“完美”不代表世界从此没有争执，而是：

- 七国都保留自己的五心／双印托管权；
- 索拉恩被从信仰与历史中正确记载，而非再次掩埋；
- 八位女主都完成个人成长；
- 三位婚约对象不是为了玩家放弃人格；
- 未被选择的五位仍是重要盟友，有自己的目标与幸福；
- 伊芙琳的纯结用于见证自愿，不用于强迫任何人和谐。

#### 婚礼演出建议

婚礼不采用“八人站成一排等玩家挑”的画面。先让玩家在安静场景中分别提出未来，再由三位候选独立会谈；最后在月环圣所举行四方共同誓言。每人说出自己愿意承担的事，也说出一件绝不放弃的自我部分。

### 22.5 旧§15　第103章A｜病结局：绯月独占（冻结为IF候选）

病结局是一条悲剧路线，不作为隐藏福利。它需要长期选择累积，不能因一次选错突然发生。

#### 基础触发

至少一位角色满足：

```text
LOVE = 100
OBSESSION ≥ 85
JEALOUSY ≥ 80
BOUNDARY_STABILITY < 45
SELFHOOD < 55
对应关系危机未完成修复
```

并且玩家至少满足两项：

- 对两位以上角色作出互相冲突的排他承诺；
- 在第61或89章刻意隐瞒关键真相；
- 三次以上把监视、控制、惩罚称作爱；
- 第94章继续含糊承诺，不选择公开协商；
- 第98章用誓约要求角色“永远不能离开”；
- 对该角色的定向罪恶感≥50，且至少一次强迫献祭未修复。

若多位角色同时满足，选择 `病化优先值 = LOVE + OBSESSION + JEALOUSY + 对应罪蚀` 最高者成为主导者。

#### 八种病爱尾声

演出保持非血腥，但明确这是灾难。

- **莉亚｜最后的安全堡垒**：她封锁城堡，认定所有接近亚克的人都会带来危险。未能逃离的女主在空置盾牌与停止回信中被暗示死亡；亚克被“保护”到再也不能出门。
- **米娅｜零号幸福箱庭**：自动构造体接管城市通讯，把其他女主标记为系统故障并逐一“排除”。亚克生活在完美运转的宅邸，却再也收不到外界消息。
- **塞雷娜｜镜中只剩两个人**：她切断所有镜路与影子，把竞争者的名字从记录中抹去。最后一幕只有亚克和她的倒影，而桌上仍摆着八只杯子。
- **芙蕾娅｜永不融化的春天**：她将冲突者冻结在无梦冰棺，声称大家只是需要长眠。亚克在温暖房间醒来，窗外整座王都没有一个脚步声。
- **莉莉丝｜没有比较就不会嫉妒**：她按一份从未让亚克看见的名单行动，其他女主接连失踪。最后她把头放到亚克掌下，问现在是否终于只看得见她。
- **伊芙琳｜没有人说不要的世界**：她用纯结改写所有人的选择，让每个人都微笑同意；肉身在静止圣所中逐渐衰亡，亚克与她被困在永远没有争执的梦。
- **奥菲利亚｜藏进龙腹的名字**：她吞下其他人的名字与记忆，龙形盘踞月环圣所。亚克还记得自己曾爱过很多人，却再也说不出任何一个名字。
- **艾拉｜唯一正确的婚约**：她以圣裁宣布其他感情皆为腐化，追随者执行肃清。婚礼钟响时，长椅上只留下七件无人领取的遗物。

#### 病结局的最后选择

在103章末仍可提供一次不逆转死亡的“承担后果”选择：

- 留下陪伴病化者；
- 拒绝并被囚禁／追杀；
- 破坏誓约让她短暂清醒，但关系与世界无法恢复原状。

这让结局保留角色悲剧，而不是把杀戮包装成成功收集。

#### 剧情结果

他不是成为新神，而是成为七罪共同使用的“第八张嘴”。五心和双印从身体中裂成七道空洞，索拉恩虽然被击败，世界却被更无人格的罪律潮汐吞没。

八位女主根据状态作最后一次呼唤；纯结不足时，这些声音无法彼此连接。画面停在没有名字的王座，系统将玩家输入的姓名逐字抹除。

#### 旧§3.1　爱慕 `LOVE`

范围：0–100，隐藏。

| 数值 | 内部标签 | 表现 |
|---:|---|---|
| 0–49 | 未达恋爱标记 | 可以是重要伙伴，但不默认存在爱情 |
| 50–79 | **好感** | 特别关注、主动寻找玩家、轻微吃醋 |
| 80–89 | **喜欢** | 承认心动，开放恋爱事件，但仍可只做伙伴 |
| 90–99 | **爱慕** | 愿意讨论长期未来，是健康婚约目标区间 |
| 100 | **疯狂** | 爱慕失去弹性，进入关系危机与病爱候选 |

达到100不是奖励。界面只表现异常：反复确认、笑容停顿、擅自安排、过滤来信、对其他女主称呼改变。完成危机任务后可回落至95左右。

旧§3.2 罪恶感区间（节选）：

| 区间 | 表现与效果 |
|---:|---|
| 80–99 | 黑魔法师可将玩家过去的欺负与献祭行为实体化；健康结局需完成赎偿主线 |
| 100 | 获得“罪冠适格”，成为七罪吞噬或主动堕落结局的核心条件之一 |

旧§3.3 边界稳定的门槛：

- 70以上：健康结局候选。
- 45–69：存在未解决冲突，终章必须补做确认事件。
- 44以下：不能进入健康婚约；高爱慕时加速病化。

旧§3.6 自我成长：

范围：0–100，隐藏。衡量角色能否在爱玩家的同时保留自己的名字、判断、同伴与未来。健康结局要求至少65；三人婚约要求每位对象至少75。

旧§3.7 罪蚀：

- 90–100：终局吞噬候选。

旧§3.8：

- `PAIR_ACCEPTANCE[A][B]`：两位女主对彼此人格、边界和共同生活意愿的认可，决定三人婚约。

三人婚约最容易失败的原因不是爱慕不够，而是玩家分别许下互相冲突的承诺，或把一位女主的付出隐藏给另外两人。

旧§7 关系阶段（节选）：

| 阶段 | 条件 | 开放内容 |
|---|---|---|
| 喜欢候选 | 隐藏爱慕≥80、完成个人任务第二段 | 恋爱确认事件，不自动锁线 |
| 誓约候选 | 爱慕90–99、信赖≥75、边界≥70、自我成长≥65 | 真名誓约、101章候选 |
| 星环关系 | 第94–98章明确确认 | 101或102章候选 |

献祭不作为健康恋爱门槛。高献祭只说明角色付出很多；若存在未偿还的强迫献祭债务，即使爱慕和信赖足够，也不能进入健康婚约。

角色可以爱慕玩家却不进入婚约，例如选择重建国家、继续友情、拒绝当前多人组合，或认为玩家尚未偿还对她造成的献祭债务。
