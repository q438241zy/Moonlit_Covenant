# 06｜战斗、职业、魔法与装备

## 1. 战斗定位

战斗采用四人出战、其余成员后备支援的回合制 JRPG 结构。核心循环为：

1. 侦察敌方源律与罪核；
2. 使用元素和职业技能削减 `BREAK`；
3. 通过信赖被动、后备支援与合击建立优势；
4. 在破防窗口使用唯一装备的誓约技能或高消耗终结技；
5. 根据Boss剧情条件选择击杀、净化、解除罪核或撤离救援。

队伍最多四人同时在场，但第30章后八位女主都能作为后备成员触发低频支援。这样既保持JRPG编成策略，也让完整角色阵容在剧情上持续有存在感。

## 2. 基础资源

### 2.1 生命值 `HP`

归零进入倒地状态。普通战斗可复苏；关键剧情战若连续倒地会影响伤势事件与信赖，不轻易永久死亡。

### 2.2 魔力 `MP`

施法、形态切换与部分职业技消耗。亚克切换源律也消耗少量MP，避免七属性无成本覆盖所有弱点。

### 2.3 破防值 `BREAK`

每名敌人拥有独立破防条。针对弱点、打断蓄力、完成场地机关和队友合击均可削减。破防后敌人一轮无法行动并受到额外伤害。

### 2.4 共鸣槽 `RESONANCE`

全队共享0–100。以下行为增加：

- 命中弱点；
- 按角色战术偏好配合；
- 救援而非无脑挡伤；
- 完成承诺型战斗目标；
- 使用双人合击。

以下行为降低：

- 亚克连续擅自替伤；
- 忽视队友明确撤退信号；
- 使用被队伍禁止的罪核技能；
- 对剧情Boss杀死可救目标。

### 2.5 罪蚀值 `CORRUPTION`

分角色与全队两层。使用罪核捷径、纵容错误信念、装备污染遗物会增加。罪蚀能提供高风险强力效果，但会改变台词、AI行动和结局条件。

### 2.6 誓约充能 `OATH_CHARGE`

每场战斗从0开始。保护誓约对象、完成战术配合、触发信赖被动和作出符合双方约定的行动可充能。达到100后可释放当前装备的唯一誓约技能。

## 3. 七种基础源律

| 源律 | 战斗特性 | 常见弱点关系 | 罪化副作用 |
|---|---|---|---|
| 金 | 破甲、导能、精准、机械控制 | 克制构造体与甲壳；易受土系重压干扰 | 叠加资源、锁定技能、过度计算 |
| 木 | 再生、毒、标记、拟态、生命感知 | 克制水生群体与无根灵体；怕高温与净化 | 复制技能、夺取增益、身份混乱 |
| 水 | 治疗、流动、减速、清除 | 克制火；受金导电与土封流影响 | 延迟行动、永久冻结、逃避回合 |
| 火 | 爆发、燃烧、士气、反击 | 克制木与冰；被水压制 | 失控追击、无法撤退、自伤增幅 |
| 土 | 防御、重击、重力、承载 | 克制金属位移与大型敌人；怕水侵蚀、木根穿透 | 吞噬素材、吸收技能、行动迟缓 |
| 光 | 显形、净化、护盾、公开誓言 | 克制暗影与伪装；被反射与傲慢机制反制 | 强制目标、唯一指令、封锁选择 |
| 暗 | 隐匿、诅咒、梦境、欲望干扰 | 克制光盾与精神敌人；受真名、公开信息影响 | 魅惑、监视、隔离与目标占有 |

相克不是简单的固定伤害剪刀石头布。Boss战更强调机制，例如火能融冰，却可能加速雪崩；光能显形暗影，却会被“唯一正确目标”反利用。

## 4. 复合与进阶属性

- 雷：金＋火，适合米娅和艾拉。
- 风：木＋水，适合莉莉丝高速移动和奥菲利亚飞行。
- 冰：水＋土，芙蕾娅专长。
- 炎：火的领域形态，莉亚和亚克后期掌握。
- 圣：光＋自愿共同信念，伊芙琳专长。
- 影：暗＋木／水，塞雷娜和莉莉丝使用方式不同。
- 时空：金＋光＋暗，主要作为短距折跃和延迟，不允许无限回溯。
- 龙：土为核心的多律复合，奥菲利亚独有。

## 5. 亚克的七属性成长

亚克每种源律拥有独立熟练度0–5：

| 等级 | 名称 | 功能 |
|---:|---|---|
| 0 | 微痕 | 仅生活用途或极弱附魔 |
| 1 | 火花 | 可造成对应属性伤害，但效率低 |
| 2 | 符印 | 解锁稳定附律与地图小机关 |
| 3 | 回路 | 可与对应女主发动双人合击 |
| 4 | 领域前阶 | 解锁一项高阶源律技能 |
| 5 | 真共鸣 | 只在遗物真共鸣后取得，可参与终章纯结 |

限制：

- 同一回合只能切换一次附律；
- 七律全部达到5也不代表亚克能替代专业角色；
- 专业角色技能拥有更高倍率、独特机制与较低消耗；
- 亚克的价值是连接、应变和触发誓约，而非全能输出。

## 6. 行动序列与阵位

### 6.1 行动序列

行动速度由角色基础速度、装备重量、状态和技能优先级决定。UI显示未来6个行动图标，允许玩家规划打断和救援。

### 6.2 阵位

- 前锋位：更易被攻击，近战伤害和护援效率提高。
- 中卫位：适合亚克、艾拉、米娅等混合角色。
- 后卫位：法师与弓手安全，但被突袭时惩罚更高。
- 飞行位：奥菲利亚特定形态可进入，不受地面陷阱但会被弓与雷针对。

## 7. 武器类型

### 剑

均衡、附律效率高。亚克的魔剑可储存七种低阶纹路，但一次只能激活一种。

### 弓

远程、标记、打断飞行敌人。伊芙琳使用圣歌弓，把治疗祷文附在箭上。

### 盾

护援、反击、阵型控制。莉亚用塔盾稳定队伍，艾拉用圆盾进行高速决斗。

### 匕首

高速度、背击、状态与标记。莉莉丝拥有对破防目标的最高单体倍率。

### 棍／魔导棍

技能模块多、可部署装置。米娅能在战斗前装配三个模块，但不能全带。

### 法杖

提高施法稳定、领域和控制。塞雷娜、芙蕾娅与奥菲利亚的法杖结构完全不同。

## 8. 角色战斗差异

### 亚克｜七律魔剑士

- 强项：弱点适应、破防、誓约触发。
- 弱项：单一属性倍率低、频繁切换耗魔。
- AI建议：优先补队伍缺失属性，不自动连续替伤。

### 莉亚｜火盾战士

- 强项：前排稳定、自动护援、火伤转盾。
- 弱项：移动慢、罪蚀高时会擅自追击。
- 成长：从“只挡”转为能指挥撤退与反击。

### 米娅｜金律发明师

- 强项：扫描、机械控制、范围与道具经济。
- 弱项：装置过热、需准备回合。
- 成长：安全意识越高，随机故障越少，但保留可控喜剧故障。

### 塞雷娜｜暗系魔法师

- 强项：控制、行动干扰、敌方增益夺取。
- 弱项：面对无欲望构造体效果较低。
- 成长：健康路线技能从单体占有转向全队保护。

### 芙蕾娅｜冰系魔法师

- 强项：减速、伤害延迟、持续治疗。
- 弱项：爆发低，过度冻结会拖长战斗。
- 成长：学会在“冻结”和“融化”间切换。

### 莉莉丝｜木影刺客

- 强项：高速、标记、背击、追击。
- 弱项：群体输出低，情绪失控时易离队位。
- 成长：从单独行动转为把标记分享给队友。

### 伊芙琳｜纯结圣女

- 强项：治疗、复苏、净化罪律、稳定誓约。
- 弱项：被沉默或孤立时能力大幅下降。
- 成长：从被动祈祷变成主动选择目标和拒绝无意义牺牲。

### 奥菲利亚｜土龙变形者

- 强项：爆发、形态切换、群体压制、探索。
- 弱项：完全龙化消耗巨大，室内受限。
- 成长：不再吞下所有增益，而是选择必要形态。

### 艾拉｜光明骑士

- 强项：快速坦克、反控制、单挑、光雷输出。
- 弱项：挑衅会提高敌方攻击性；罪蚀高时会锁定“有罪目标”不换人。
- 成长：终极技能从执行命令变为斩断控制。

## 9. 信赖被动技能

每位女主拥有一项信赖被动。基础触发公式：

```text
触发率 = 10% + TRUST × 0.25% + TEAM_COHESION × 0.10%
上限 = 45%
同一被动冷却 = 3个角色行动
```

若当前行为违背角色明确约定，例如答应撤退却继续强攻，则本回合该角色被动不触发。

| 角色 | 信赖被动 | 效果 |
|---|---|---|
| 莉亚 | 可信之盾 | 自动格挡一次高伤攻击 |
| 米娅 | 叮当支援 | 使用道具或命中弱点时追加装置 |
| 塞雷娜 | 无声提醒 | 提前暴露致命技能或削弱施术者 |
| 芙蕾娅 | 缓死霜 | 将致命伤延迟到回合末 |
| 莉莉丝 | 先一步 | 敌人锁定亚克或低血队友时先制削弱 |
| 伊芙琳 | 纯结回声 | 提供一次摆脱控制或罪律的判定 |
| 奥菲利亚 | 龙翼介入 | 降低一次全体攻击伤害 |
| 艾拉 | 不服从救援 | 解除一次控制并反击 |

## 10. 默契与合击

`SYNERGY`为0–100，可见。它主要通过实际共同战斗增加，不因送礼直接提升。

- 20：解锁基础追击。
- 40：解锁双人技能第一形态。
- 60：合击可改变场地。
- 80：解锁角色专属高级合击。
- 100：可在终章纯结技中成为稳定节点。

### 代表双人合击

- 亚克＋莉亚 `赤盾黎月`：莉亚架盾推进，亚克切换弱点附律反斩。
- 亚克＋米娅 `七律调试`：米娅扫描后临时提高对应附律等级。
- 亚克＋塞雷娜 `镜后真名`：影步换位并揭露敌方伪装。
- 亚克＋芙蕾娅 `融雪剑线`：先冻结破防条，再以火或光引爆。
- 亚克＋莉莉丝 `双影追月`：共享标记连续背击。
- 亚克＋伊芙琳 `微光不献祭`：将替伤效果改为全队均摊。
- 亚克＋奥菲利亚 `龙脊锚落`：空中俯冲后固定Boss位置。
- 亚克＋艾拉 `不服从双刃`：解除命令类状态并反击。

### 女主间合击

至少提供以下组合，避免所有关系只围绕亚克：

- 莉亚＋芙蕾娅 `赤盾静雪`
- 米娅＋芙蕾娅 `移动温室`
- 莉莉丝＋艾拉 `瓦尔哈拉双刃`
- 塞雷娜＋伊芙琳 `夜中星歌`
- 奥菲利亚＋伊芙琳 `双圣女拒祭`
- 米娅＋塞雷娜 `镜面调试`

## 11. 誓约系统与唯一装备槽

### 11.1 解锁条件

每位女主的誓约技能需要：

- `TRUST ≥ 60`
- `INTIMACY ≥ 55`
- `SYNERGY ≥ 50`
- 完成个人任务第二阶段
- 没有未处理的重大边界事件

### 11.2 装备规则

- 亚克只有 **一个誓约槽 `OATH_SLOT`**。
- 一次只能装备一位角色的誓约技能。
- 只能在营地、城镇或特定存档点更换。
- 每场战斗通常只能释放一次。
- 更换不自动降低其他角色好感；角色可根据关系阶段产生自然对话。
- 三人婚约结局不会让亚克同时装备三项誓约技，以维持战斗平衡；完美结局会把三人誓约组合成一个动态技能。

### 11.3 八项誓约技

| 角色 | 誓约技 | 核心效果 |
|---|---|---|
| 莉亚 | 赫斯特不落城 | 全队受到致命伤前保留1点生命，并立即发动一次反击破防 |
| 米娅 | 零号机·无限工坊 | 重构战场机关，复制一项非誓约战术技能并无消耗释放 |
| 塞雷娜 | 无月葬礼 | 解除全队精神控制，封锁Boss一次阶段转换或分身复活 |
| 芙蕾娅 | 春回霜华 | 全队复苏与持续净化，将冻结、恐惧、疲劳转化为护盾 |
| 莉莉丝 | 瓦尔哈拉无影 | 标记真身，全队对弱点发动无视闪避的连锁追击 |
| 伊芙琳 | 黎明仍会来 | 全队复苏、净化，并短暂允许七律无冲突叠加 |
| 奥菲利亚 | 诺德天穹真形 | 龙形吞噬一次全场灾害，并返还为七属性吐息 |
| 艾拉 | 晨光不服从 | 取消敌方绝对规则，使全队一次行动不受禁令与反制 |

## 12. 三人完美结局的终极誓约技

第102章前最终战若满足三人婚约条件，`OATH_SLOT`显示为“三冠共誓”，但仍视为一个技能。技能由所选三位角色模块组合：

- 防御模块：莉亚／芙蕾娅／奥菲利亚
- 控制模块：塞雷娜／伊芙琳／艾拉
- 输出模块：米娅／莉莉丝／艾拉／奥菲利亚
- 恢复模块：伊芙琳／芙蕾娅

系统按三人组合自动生成技能名与演出，但数值使用统一预算，避免某些组合明显弱于其他组合。

## 13. 状态效果

### 常规负面

燃烧、中毒、冻结、麻痹、流血、沉默、破甲、迟缓、恐惧。

### 罪律负面

- `估值`：行动被换算为资源，低价值技能可能被锁。
- `拟态`：敌人复制最近使用技能。
- `沉眠`：角色延迟行动并逐渐失去战意。
- `怒追`：强制攻击最近伤害来源。
- `吞忆`：技能暂时被Boss夺走。
- `唯一答案`：只能选择系统指定行动。
- `独占`：只能对一个目标行动，无法支援其他人。

这些状态可通过对应角色成长技能、真共鸣遗物和伊芙琳纯结净化解除。

## 14. 装备槽

每名角色拥有：

- 主武器1
- 防具1
- 饰品2
- 战术模块1
- 亚克额外拥有誓约槽1

战术模块改变技能机制，不单纯堆数值。例如莉亚可选择“全队分担”或“单体绝对护援”，米娅可选择安全型或过载型装置。

### 代表武器成长

- 黎月：七道空槽依章节点亮，最终不属于任何国家。
- 赤誓：记录莉亚每次选择撤退而不是死守的时刻。
- 叮当三号：安全组件会随着米娅成长真正装上。
- 无眠镜：镜面数量越来越少，反而更强，因为每一面都经许可使用。
- 春眠：从封冻法杖改造成融雪与种子保存工具。
- 昼盲／夜醒：由相互竞争的双刃变成共享标记。
- 微光：礼仪装饰被拆除，保留伊芙琳自己选择的铃片。
- 祖语：删除强制祖王命令，加入奥菲利亚自选名。
- 晨罚：从执行命令的光剑改名“晨问”，技能可中断友方错误命令。

## 15. 制作与强化

强化材料来自怪物生态、支线与国家产业。关键原则：

1. 普通材料可重复获取，避免错过Build。
2. 叙事性材料不用于不可逆数值最优解，防止玩家为强度牺牲故事。
3. 米娅负责魔具，莉亚负责防具维护，芙蕾娅处理药剂保存，奥菲利亚提供龙材许可。
4. 稀有龙鳞、记忆冰与灵体材料必须由来源同意或净化后获得，不能鼓励盗采。

## 17. AI战斗倾向

AI自动战斗必须同时读取：当前战术、信赖、默契、角色成长、罪蚀与玩家明确禁用行为。

- 高信赖不等于擅自替玩家做所有决定。
- 塞雷娜若被禁止使用监视镜，不应在自动战斗绕过。
- 莉亚不会因好感高就无视撤退命令。
- 米娅的故障率受安全意识影响，但不应在关键剧情战随机毁局。
- 病爱状态可改变优先目标和台词，但重要路线前必须有明确预警。

## 18. 难度与可访问性

- 剧情模式允许自动推荐弱点与关系安全选项。
- 标准模式保留完整机制。
- 战术模式提高Boss阶段复杂度，不提高关系数值惩罚。
- 提供色觉图标、字幕、战斗速度、QTE关闭、重复失败跳过机制。
- 自由输入误判可在日志中查看意图分类并重新确认，避免AI误解直接毁掉路线。
