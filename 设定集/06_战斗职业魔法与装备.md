# 06｜战斗、职业、魔法与装备

## 1. 战斗定位

建议采用 **可见行动序列的回合制战斗**。玩家同时操作4名上场角色，最多5名角色在后备位。战斗强调破防、元素状态、即时换人与关系合击，避免只靠等级和单一大招碾压。

核心节奏：

`侦察弱点 → 建立破防值 → 控制行动序列 → 触发失衡 → 使用共鸣合击 → 应对Boss规则变化`

## 2. 基础资源

### 生命值 HP

降至0进入“倒地”，不是立即死亡。倒地角色可在三回合内被救起；特定剧情战有永久失败条件。

### 魔力 MP

用于主动魔法与职业技能。普通攻击、防御、成功触发弱点可恢复少量MP，鼓励主动轮转。

### 破防值 BREAK

敌人拥有独立韧性条。使用弱点属性、盾击、背击和特定控制技能削减韧性。归零后敌人进入一至两回合失衡，受到额外伤害并可能中断大招。

### 共鸣槽 RESONANCE

全队共享，范围0–100。以下行为增加共鸣：

- 援护队友；
- 命中弱点；
- 使用符合角色成长的行为，例如塞雷娜保护全队、莉亚主动撤防换位；
- 回应战斗中的AI对话提示；
- 完成精准防御。

达到50可发动双人合击，100可发动队伍契约技。

### 边界护盾 BOUNDARY

主要用于剧情Boss和关系系统。它代表角色的意志完整度。魅惑、控制、身份抹除会先攻击边界护盾；高信赖和“自选之名”被动能提高抗性。

## 3. 行动序列

角色速度决定初始顺序。风、雷、暗影技能可推前己方或延后敌人；冰系擅长整体减速；土系技能会牺牲速度换取稳定。时空术只能小幅调整顺序，不能无限连动。

每回合玩家可选择：普通攻击、技能、防御、道具、换人、战术指令。换人每轮首次免费，之后消耗共鸣，鼓励活用后备而不形成无成本循环。

## 4. 队伍阵位

- **前排两格**：更易被近战攻击，获得护盾和反击加成。
- **后排两格**：远程与施法更安全，但遭突进时破防损失更大。
- 莉亚可用 `阵地命令` 交换队形。
- 莉莉丝与艾拉可穿越阵位。
- 奥菲利亚完全龙化时暂时占用两个阵位。

## 5. 武器类型

### 剑

均衡、连击、元素附魔。使用者：亚克、艾拉，莉亚副手。

### 弓

远程弱点、飞行敌人、标记。使用者：伊芙琳；部分NPC弓手。

### 盾

护援、反击、阵型。使用者：莉亚、艾拉。

### 匕首

高速、背击、异常、追击。使用者：莉莉丝。

### 棍／魔导棍

物理敲击、装置部署、属性模块。使用者：米娅。

### 法杖

魔力放大、领域、治疗与控制。使用者：塞雷娜、芙蕾娅、奥菲利亚人形。

## 6. 元素规则

基础五系与进阶五系不采用僵硬的单环克制，而采用“状态反应”。

| 状态组合 | 反应 | 效果 |
|---|---|---|
| 水／湿润 + 雷 | 传导 | 雷伤扩散至相邻目标 |
| 水／湿润 + 冰 | 冻结 | 降速，韧性低时跳过行动 |
| 火 + 风 | 扬炎 | 扩大火伤范围，缩短持续时间 |
| 火 + 土甲 | 熔裂 | 大幅削减护甲与破防值 |
| 雷 + 金属装甲 | 过载 | 禁用机械技能一回合 |
| 风 + 暗雾 | 散影 | 暴露隐身与分身本体 |
| 圣 + 诅咒 | 净化 | 移除或转化负面状态 |
| 暗 + 增益 | 侵蚀 | 吸收、复制或反转增益 |
| 冰 + 炎 | 热震 | 立即造成一次无属性破防伤害 |
| 时空 + 任意延迟术 | 回响 | 让技能再次结算，但威力降低 |

圣、暗不是互相绝对克制。圣系擅长维持秩序，暗系擅长揭露和侵蚀隐藏结构；面对扭曲圣术时，暗系反而可能是最佳解法。

## 7. 职业与角色战斗差异

### 亚克｜魔剑士

- 强项：适应不同区域、破防、触发合击。
- 弱项：纯粹输出不如专职角色，过度护援会迅速倒地。
- 成长分支：元素剑、守护剑、时序剑。

### 莉亚｜盾战士

- 强项：全队生存、嘲讽、反击、稳定阵形。
- 弱项：速度慢，若玩家无脑让她承担全部伤害会崩盘。
- 独有机制 `守线`：每挡下一次攻击累积一层；主动换位或撤退可把层数转为共鸣，而非永远站桩。

### 米娅｜魔具发明师

- 强项：扫描、范围输出、解谜、道具效率。
- 弱项：装置需要预热，部分技能存在可控故障率。
- 独有机制 `模块`：战前选择两种模块，如雷线圈、冰喷嘴、修复臂、诱饵机。

### 塞雷娜｜暗系魔法师

- 强项：控制、吸取、打断敌方增益、处理分身。
- 弱项：直接治疗能力低，暗抗敌人需要队友创造状态。
- 独有机制 `秘密`：敌人使用技能后暴露秘密标签，塞雷娜可消耗标签封锁该技能。

### 芙蕾娅｜冰系魔法师

- 强项：减速、减伤、冻结、持续恢复。
- 弱项：爆发较低，Boss免疫冻结时需要转用“冷静”减益。
- 独有机制 `温度`：连续冰术降低温度，强化控制但也减慢己方；使用融水与治疗可回温。

### 莉莉丝｜暗影刺客

- 强项：单体爆发、背击、追击、击杀收割。
- 弱项：正面防御低，对多目标战依赖烟幕。
- 独有机制 `影标`：标记目标后，任何队友造成破防都会触发她的追击。

### 伊芙琳｜圣女

- 强项：治疗、净化、免死、飞行敌人。
- 弱项：被沉默或恐惧时能力受限，需通过勇气技能克服。
- 独有机制 `祷歌`：连续施法形成歌段；被打断会损失层数，队友护援可保护歌段。

### 奥菲利亚｜龙族圣女

- 强项：形态切换、群体压制、空战、全属性抗性。
- 弱项：完全龙化消耗高，结束后进入疲劳。
- 独有机制 `龙形值`：受到、造成伤害和使用祖语累积，满值可变形。

### 艾拉｜光明骑士

- 强项：高速坦克、决斗、反暗与解除控制。
- 弱项：挑衅会提高敌人攻击性，判断错误会使队伍承压。
- 独有机制 `反逆`：主动拒绝敌方命令、控制或脚本机制时获得层数，提高反击。

## 8. 技能成长范例

角色技能不只靠等级升级，也受剧情成长影响。

| 角色 | 初期表现 | 成长后变化 |
|---|---|---|
| 莉亚 `不动壁垒` | 独自吸收大量伤害 | 可指定队友共同分担，并获得共鸣 |
| 米娅 `自动炮台` | 高伤但可能误伤护盾 | 完成伦理任务后可选安全模式或超载模式 |
| 塞雷娜 `夜幕庇护` | 优先保护亚克 | 尊重队伍后变为全员均等保护 |
| 芙蕾娅 `冰棺` | 只冻结目标 | 可选择保护濒死队友，不再把冻结当惩罚 |
| 莉莉丝 `护主反射` | 仅对亚克触发 | 信任队伍后对任何低生命伙伴触发 |
| 伊芙琳 `祈愿屏障` | 害怕时失败率上升 | 勇气事件后生命越低越稳定 |
| 奥菲利亚 `祖语震慑` | 借祖先权威压制 | 自选名后以自身意志施放，免疫反制 |
| 艾拉 `挑衅号令` | 无差别提高风险 | 成长后可明确选择承担风险的对象 |

## 9. 双人合击

建议制作至少16组，首批重点如下：

| 组合 | 名称 | 效果与演出 |
|---|---|---|
| 亚克＋莉亚 | `赤盾流星` | 莉亚弹射亚克越过敌阵，亚克落地破防；随后她接住他回到阵线。 |
| 亚克＋米娅 | `黎月过载` | 米娅为魔剑临时加装线圈，亚克连续元素斩；有夸张冒烟演出。 |
| 亚克＋塞雷娜 | `镜月双生` | 塞雷娜制造镜像，真假亚克同时攻击，最后由玩家选择本体落点。 |
| 亚克＋芙蕾娅 | `融雪之刃` | 先冻结敌方伤口再以火刃热震，兼具破防与治疗回响。 |
| 亚克＋莉莉丝 | `无声交错` | 正面剑击吸引注意，莉莉丝从背后触发全部影标。 |
| 亚克＋伊芙琳 | `星歌剑阵` | 圣歌箭化为剑轨，提高全队命中并净化诅咒。 |
| 亚克＋奥菲利亚 | `骑龙不是坐骑` | 亚克短暂站上龙背俯冲；对白强调这是双方同意的战术合作。 |
| 亚克＋艾拉 | `不服输的双光` | 两人竞争式连斩，最后同时解除敌方控制场。 |
| 莉亚＋塞雷娜 | `赤盾夜幕` | 盾墙与暗幕合并，使敌人无法锁定后排。 |
| 米娅＋芙蕾娅 | `移动温室` | 部署冰晶温室，持续治疗并产生水、冰反应。 |
| 莉莉丝＋艾拉 | `瓦尔哈拉双刃` | 姐妹一明一暗夹击，对控制型敌人额外伤害。 |
| 伊芙琳＋奥菲利亚 | `双圣女宣言` | 同时解除强制契约，并为全队恢复边界护盾。 |

## 10. 队伍契约技

### 初期｜四星临时誓约

亚克、莉亚、米娅、塞雷娜共同发动。莉亚固定阵线，米娅定位核心，塞雷娜封锁逃路，亚克完成破核。第16章首次出现。

### 中期｜五心轮转

获得三颗以上世界之心后解锁。玩家选择一颗心作为主属性，其余角色提供支援。

### 真终极｜黎明月蚀契约

九人共同发动，不是单一伤害动画。战斗中依次出现八次选择：玩家必须接受伙伴提供的帮助，而不是选择“独自承担”。全部完成后才能打破莫尔坎的单向契约。

## 11. 状态效果

### 常规负面

燃烧、湿润、感电、冻结、流血、毒、失明、沉默、恐惧、迟缓、破甲、诅咒。

### 叙事型负面

- `被命名`：行动被敌人预设，需用自选之名或队友呼唤解除。
- `孤立`：无法获得支援技能，需换位或关系行动解除。
- `过度保护`：角色强制替队友承伤；通过明确战术指令解除。
- `被观察`：隐私边界受损，敌人复制技能；摧毁镜面或塞雷娜反制。
- `冻结记忆`：忘记最近一回合行动，需时间回声或芙蕾娅解冻。

装备不随机生成大量无意义词条。每件稀有装备至少与地点、角色或支线有关，并提供一种玩法改变。

## 13. 制作与强化

米娅负责武器模块，莉亚负责防具保养，芙蕾娅负责药剂与保存，塞雷娜负责诅咒净化，奥菲利亚负责龙材鉴定。这样营地系统能让每名角色参与，不把所有制作功能都压在一人身上。

素材分为普通、区域、记忆、誓言四类。誓言素材来自角色任务，不能重复刷取，只用于改变技能性质而非单纯加攻击力。

## 14. 等级与章节建议

- 第1章：Lv.1
- 第15章：Lv.12左右
- 第30章：Lv.24左右
- 第45章：Lv.34左右
- 第60章：Lv.43左右
- 第75章：Lv.51左右
- 第90章：Lv.58左右
- 第99章：Lv.65左右

采用软等级同步，防止新加入角色落后。后续女主加入时自动接近队伍平均等级，并提供专属教学战。

## 15. AI战斗倾向

玩家可为后备与自动角色设置：保守、均衡、进攻、支援、节省MP、自定义条件。角色人格会影响默认建议，但玩家拥有最终控制权。

- 莉亚默认优先保护低生命队友。
- 米娅默认先扫描未知敌人。
- 塞雷娜初期默认亚克优先，剧情成长后改为全队优先。
- 芙蕾娅避免让温度降至危险值。
- 莉莉丝优先追击破防目标。
- 伊芙琳优先解除致命异常。
- 奥菲利亚在Boss战保留龙形值。
- 艾拉优先解除控制并锁定精英敌人。

## 16. 难度与可访问性

- 剧情模式允许自动弱点提示、失败后降低Boss当前阶段韧性。
- 标准模式完整使用所有机制。
- 战术模式提高敌人组合和资源压力，不单纯增加血量。
- 可关闭快速闪光、屏幕震动、镜面扭曲与巨型虫类特写。
- 关系选择可开启“意图提示”，显示选项是安慰、挑战、设界或回避，避免语义误判。
